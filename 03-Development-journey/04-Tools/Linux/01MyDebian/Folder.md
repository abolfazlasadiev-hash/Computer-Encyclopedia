# بررسی کامل پوشه‌ی v2rayN در لینوکس

مسیر پوشه‌ی تو اینه:

```
~/Applications/v2rayN/v2rayN-linux-64/
```

این پوشه یک بسته‌ی کامل از v2rayN برای لینوکس ۶۴ بیتی است. اجزای آن را می‌توان به چند گروه تقسیم کرد:

۱. رابط گرافیکی
۲. موتورهای پروکسی
۳. داده‌های مسیریابی
۴. تنظیمات
۵. کتابخانه‌های نرم‌افزاری و گزارش‌ها



## ۱. فایل‌ها و پوشه‌های اصلی

`v2rayN`

فایل اجرایی اصلی رابط گرافیکی است. از طریق آن سرورها را مدیریت می‌کنی، تنظیمات را تغییر می‌دهی و هسته‌های پروکسی را کنترل می‌کنی.

`bin/`

شامل موتورهای پروکسی، ابزارهای جانبی و داده‌هایی است که برای اتصال و مسیریابی لازم‌اند.

`binConfigs/`

شامل فایل‌های پیکربندی و اسکریپت‌های کمکی برای محیط لینوکس است.

`guiConfigs/`

تنظیمات و دیتابیس داخلی رابط گرافیکی را نگه می‌دارد.

`guiLogs/`

گزارش‌های روزانه‌ی برنامه؛ برای بررسی خطاها و عیب‌یابی اتصال مفید است.

## ۲. پوشه‌ی `bin/`؛ موتورهای اتصال

این قسمت مهم‌ترین بخش فنی برنامه است. رابط گرافیکی به‌تنهایی اتصال پروکسی را برقرار نمی‌کند؛ معمولاً یک هسته‌ی اجرایی این کار را انجام می‌دهد.

|نام|وظیفه|
|---|---|
|`xray/xray`|هسته‌ی Xray برای برقراری اتصال‌های پروکسی|
|`v2fly`|هسته‌ی V2Ray از پروژه‌ی V2Fly|
|`v2fly_v5`|نسخه‌ی دیگر هسته‌ی V2Fly|
|`sing_box/sing-box`|موتور پروکسی و مسیریابی sing-box|
|`mihomo/mihomo`|موتور Mihomo، مرتبط با اکوسیستم Clash|
|`hysteria`، `hysteria2`|ابزارهای مربوط به پروتکل Hysteria|
|`tuic`|پیاده‌سازی پروتکل TUIC|
|`juicity`|پیاده‌سازی پروتکل Juicity|
|`brook`|ابزار پروکسی Brook|
|`naiveproxy`|ابزار پروکسی NaiveProxy|
|`mieru`|موتور پروکسی Mieru|
|`overtls`|ابزار مرتبط با انتقال پروکسی روی TLS|
|`shadowquic`|ابزار مرتبط با انتقال مبتنی بر QUIC|

وجود این فایل‌ها به معنی فعال بودن همه‌ی آن‌ها نیست. برنامه بسته به نوع سرور، تنظیمات و قابلیت‌های نسخه‌ی نصب‌شده از هسته‌ی مناسب استفاده می‌کند.

### داده‌های داخل `bin/`

- `Country.mmdb`:
- دیتابیس جغرافیایی IPها که می‌تواند برای شناسایی کشور یا موقعیت تقریبی IP استفاده شود.
    
- `geoip.dat`: 
- داده‌های مربوط به قواعد مبتنی بر آدرس IP.
    
- `geoip.metadb`: 
- فایل داده‌ی مرتبط با اطلاعات GeoIP؛ کاربرد دقیق آن به نسخه و ابزار مصرف‌کننده بستگی دارد.
    
- `geoip-only-cn-private.dat`: 
- مجموعه‌ی خاصی از قواعد IP، مرتبط با چین و محدوده‌های خصوصی.
    
- `geosite.dat`:
- مجموعه‌ی دسته‌بندی دامنه‌ها برای قوانین مسیریابی.
    
- `cache.db`: 
- دیتابیس کش؛ محتوای دقیق آن را باید با بررسی نوع و ساختارش مشخص کرد.
    

### پوشه‌ی `srss/`

در آن فایل‌هایی با پسوند `.srs` وجود دارد. این فایل‌ها معمولاً مجموعه‌قواعد فشرده‌ی دامنه یا IP برای موتورهای پشتیبانی‌کننده از این قالب هستند.

برای مثال:

- `geosite-google.srs`:
- قواعد مرتبط با دسته‌ی Google
    
- `geosite-telegram.srs`: 
- قواعد مرتبط با دسته‌ی Telegram
    
- `geosite-netflix`
- در این پوشه وجود ندارد؛ در عوض `geoip-netflix.srs` موجود است.
    
- `geosite-category-ads-all.srs`: 
- قواعد مرتبط با دسته‌ی تبلیغات
    
- `geoip-private.srs`:
- قواعد مرتبط با محدوده‌های IP خصوصی
    

این نام‌ها دسته‌بندی موردنظر را نشان می‌دهند؛ اینکه هر دسته دقیقاً چه دامنه‌ها یا IPهایی را شامل می‌شود به محتوای فایل بستگی دارد.

## ۳. پوشه‌ی `binConfigs/`؛ پیکربندی و اسکریپت‌ها

|فایل|توضیح|
|---|---|
|`config.json`|پیکربندی مورد استفاده‌ی برنامه یا یکی از اجزای آن|
|`configPre.json`|پیکربندی اولیه یا پیش‌فرض احتمالی|
|`proxy_set_linux_sh.sh`|اسکریپت مرتبط با تنظیم پراکسی در لینوکس|
|`run_as_sudo.sh`|اسکریپت اجرای یک عملیات با دسترسی مدیر|
|`kill_as_sudo.sh`|اسکریپت توقف یک پردازش با دسترسی مدیر|

از روی نام فایل‌ها نمی‌توان با قطعیت گفت دقیقاً چه فرمان‌هایی اجرا می‌شوند. برای بررسی ایمن، ابتدا محتوایشان را بخوان:

```
cd ~/Applications/v2rayN/v2rayN-linux-64
less binConfigs/proxy_set_linux_sh.sh
```

همین روش برای فایل‌های دیگر هم قابل استفاده است.

هشدار: اسکریپت‌های `sudo` را بدون بررسی اجرا نکن. آن‌ها ممکن است تنظیمات شبکه یا پردازش‌های سیستم را تغییر دهند.

## ۴. پوشه‌ی `guiConfigs/`؛ تنظیمات برنامه

### `guiNConfig.json`

فایل متنی JSON است و معمولاً تنظیمات رابط گرافیکی را نگه می‌دارد. موارد دقیق به پیاده‌سازی برنامه بستگی دارند.

برای مشاهده:

```
less guiConfigs/guiNConfig.json
```

### `guiNDB.db`

یک فایل دیتابیس است؛ احتمال دارد SQLite باشد، اما ابتدا نوع فایل را بررسی کن:

```
file guiConfigs/guiNDB.db
```

اگر SQLite باشد، ممکن است اطلاعات داخلی برنامه در آن ذخیره شده باشد. پیش از حذف یا ویرایش این فایل از تنظیماتت نسخه‌ی پشتیبان بگیر.

## ۵. پوشه‌ی `guiLogs/`؛ گزارش‌های روزانه

فایل‌هایی مثل `2026-10-17.txt` و `2026-10-18.txt` گزارش‌های مربوط به روزهای مختلف هستند.

برای خواندن آخرین خطوط گزارش امروز:

```
tail -n 100 guiLogs/2026-10-18.txt
```

برای پیدا کردن خطاهای احتمالی:

```
grep -iE 'error|failed|exception' guiLogs/*.txt
```

این گزارش‌ها در عیب‌یابی مشکلاتی مثل اجرا نشدن هسته، خطای پیکربندی یا شکست اتصال مفیدند. قبل از انتشار گزارش، اطلاعات حساس احتمالی مثل IP و مشخصات سرورها را بررسی کن.

## ۶. پوشه‌ی `guiTemps/`

این پوشه احتمالاً برای فایل‌های موقت رابط گرافیکی است. خالی بودن آن در خروجی `tree` لزوماً مشکل نیست؛ ممکن است برنامه فقط هنگام اجرا فایل‌هایی در آن بسازد.

فعلاً نیازی به دست‌کاری آن نیست.

## ۷. پوشه‌ی `AmazTool/`

از روی اسم به‌تنهایی نمی‌توان کاربرد دقیق آن را تعیین کرد. ممکن است ابزار جانبی یا بخشی از بسته‌ی توزیع‌شده باشد. برای بررسی، این دستور را اجرا کن:

```
find AmazTool -maxdepth 2 -type f
```

## ۸. کتابخانه‌های `.so`

فایل‌های زیر کتابخانه‌های بومی لینوکس هستند:

|فایل|کاربرد|
|---|---|
|`libe_sqlite3.so`|کتابخانه‌ی مرتبط با SQLite و دسترسی به دیتابیس|
|`libHarfBuzzSharp.so`|پردازش و شکل‌دهی متن و فونت|
|`libSkiaSharp.so`|رسم گرافیکی و پردازش تصویر|
|`sing_box/libcronet.so`|کتابخانه‌ی همراه sing-box؛ کاربرد دقیق آن به نسخه‌ی بسته بستگی دارد|

این فایل‌ها را به‌صورت تصادفی حذف نکن؛ برنامه ممکن است برای اجرا به آن‌ها نیاز داشته باشد.

## ۹. فایل‌های تصویری

- `v2rayN.png`: تصویر آیکون برنامه، مناسب برای محیط‌های لینوکسی.
    
- `v2rayN.icns`: قالب آیکون رایج در macOS؛ وجود آن در بسته‌ی لینوکس به معنی نیاز GNOME به این فایل نیست.
    

## ۱۰. آیا این پوشه باید در `Applications` بماند؟

بله، نگه‌داشتن برنامه‌های قابل‌حمل در `~/Applications` یک انتخاب قابل‌قبول است. این مسیر بخشی از سیستم‌عامل نیست؛ پوشه‌ای در Home کاربر توست.

چند توصیه:

- کل پوشه‌ی `v2rayN-linux-64` را یکجا نگه دار.
    
- فایل‌های داخلی `bin` و تنظیمات را دستی جابه‌جا نکن.
    
- برای اجرای راحت‌تر می‌توان یک میان‌بر دسکتاپ یا ورودی منو ایجاد کرد.
    
- از فایل‌های تنظیمات و دیتابیس در صورت نیاز نسخه‌ی پشتیبان بگیر.
    
- اگر برنامه را به مسیر دیگری منتقل کنی، اسکریپت‌ها یا مسیرهای ذخیره‌شده ممکن است به بررسی نیاز داشته باشند.
    

جمع‌بندی: این پوشه یک بسته‌ی برنامه‌ی v2rayN است که رابط گرافیکی را به موتورهای اتصال، قواعد مسیریابی، تنظیمات و کتابخانه‌های موردنیاز متصل می‌کند. برای تشخیص دقیق موارد مبهم، بهترین قدم بعدی بررسی محتویات `AmazTool` یا فایل‌های اسکریپت است؛ بدون اینکه چیزی را اجرا یا حذف کنی.
