This roadmap is a **progressive frontend journey**. Each project requires you to apply specific skills—not necessarily learn something completely new.

Below, I'll explain **what each section and project requires from you**.

# Before You Start: What You Need

### Basic tools

- A code editor (such as VS Code)
    
- A modern web browser
    
- Browser DevTools
    
- Basic file/folder management
    
- Git and GitHub (strongly recommended from the beginning)
    

### Learning mindset

For every project, try to:

1. Build it yourself first.
    
2. Avoid copying tutorials line by line.
    
3. Break the project into small tasks.
    
4. Debug your own errors.
    
5. Improve the project after finishing it.
    
6. Upload finished projects to GitHub.

# What You Should Do for Every Project

I recommend using this checklist:

### 1. Plan

- What features does the project need?
    
- What information/data will it use?
    
- What should the layout look like?
    

### 2. Build

- Start with HTML structure.
    
- Add CSS styling.
    
- Add JavaScript only when needed.
    

### 3. Make it responsive

Test:

- 📱 Mobile
    
- 💻 Laptop
    
- 🖥️ Large screens
    

### 4. Improve it

After the basic version works, add:

- Better design
    
- Error handling
    
- Empty states
    
- Loading states
    
- Accessibility
    
- Responsive improvements
    

### 5. Publish it

For each important project:

- Push code to GitHub
    
- Deploy it online
    
- Add screenshots
    
- Write a README

## My recommendation

Don't rush to complete **100 projects** just to check the boxes.

For each project, ask yourself:

> **Can I rebuild this without looking at the solution?**

If yes, move forward. If not, repeat it or build a similar project with a different design.

A good strategy is:

- **Projects 1–40:** Focus on UI and layout.
    
- **Projects 41–60:** Focus on JavaScript logic.
    
- **Projects 61–80:** Focus on interactivity and applications.
    
- **Projects 81–100:** Build portfolio-quality applications.
