## 📌 Overview

**Personal Profile Page** is the first project in my frontend development learning roadmap.

The project is a simple personal webpage designed to introduce myself and provide basic information about who I am, what I am learning, my skills, my hobbies, and where people can find me online.

The primary purpose of this project is **not to create a visually complex website**, but to build a strong foundation in **HTML5** and learn how webpages are structured.

# 📚 HTML Concepts Practiced

## 1. HTML Document Declaration

The document begins with:

```html
<!DOCTYPE html>
```

This tells the browser that the document uses the modern HTML5 standard.

---

## 2. HTML Language

The root element specifies the language of the document:

```html
<html lang="en">
```

The `lang` attribute tells browsers and assistive technologies that the primary language of the page is English.

---

## 3. Character Encoding

The page uses UTF-8:

```html
<meta charset="UTF-8">
```

UTF-8 allows the webpage to correctly display a wide range of characters and symbols.

---

## 4. Responsive Viewport

The page includes:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

This tells mobile browsers how to scale and display the webpage.

Although the project does not contain responsive CSS yet, learning this meta tag is an important part of creating modern webpages.

---

## 5. Page Title

The browser tab title is defined using:

```html
<title>Abolfazl Asadi | Personal Profile</title>
```

The `<title>` element belongs inside the `<head>` section.

# 🧩 Semantic HTML

One of the important concepts practiced in this project is **semantic HTML**.

Instead of putting everything inside generic `<div>` elements, the page uses elements that describe the purpose of their content.

For example:

```html
<header>
```

is used for introductory content.

```html
<main>
```

contains the primary content of the page.

```html
<section>
```

groups related content.

```html
<footer>
```

contains footer information.

Semantic HTML makes the structure easier for:

- Developers
    
- Browsers
    
- Search engines
    
- Screen readers
    
- Accessibility tools
    

to understand.

# 🖼️ Images

The project uses an image with the `<img>` element:

```html
<img
    src="profile.jpg"
    alt="Profile picture of Abolfazl Asadi"
    width="200"
>
```

### `src`

The `src` attribute specifies the location of the image.

```html
src="profile.jpg"
```

Because the image is stored in the same directory as `index.html`, only the filename is required.

### `alt`

The `alt` attribute provides alternative text:

```html
alt="Profile picture of Abolfazl Asadi"
```

This is important for accessibility and provides descriptive text if the image cannot be displayed.
