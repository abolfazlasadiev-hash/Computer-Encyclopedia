This is the **final project in Category 01 — HTML Fundamentals**. 🎯

Projects 1–9 focused on individual HTML pages. Project 10 brings those ideas together into a small **multi-page personal website** with navigation connecting all the pages.

The key goal is not visual design yet. **Build a complete, well-structured website using HTML only.**

---

# 🎯 Project Goal

Create a personal website containing multiple connected HTML pages.

Your website should include:

- Home page
    
- About page
    
- Resume page
    
- Projects page
    
- Blog page
    
- Contact page
    
- Navigation between all pages
    
- Consistent semantic structure
    
- Images with meaningful `alt` text
    
- Internal links
    
- External links
    
- Email link
    
- Footer on every page
    

You will **not use CSS or JavaScript** yet.

# 🔗 The Most Important Part: Internal Links

Project 10 is where you need to understand the difference between:

### External link

```html
<a href="https://example.com">
    External Website
</a>
```

and:

### Internal link

```html
<a href="about.html">
    About Me
</a>
```

Because your files are in the same directory, you can use:

```text
index.html
about.html
resume.html
projects.html
blog.html
contact.html
```

as relative paths.


```text
About → Resume
```

Then:

```text
Resume → Projects
```

## 3. Test links in both directions

Don't just test:

```text
Home → About
```

Test:

```text
About → Home
```

and:

```text
Projects → Contact
```

and:

```text
Contact → Blog
```

Every page should be able to reach the other pages through your navigation.

---

## 4. Inspect HTML

Open **DevTools → Elements**.

Check that every page contains:

```text
<header>
<nav>
<main>
<footer>
```

where appropriate.

---

## 5. Check the Console

Open:

**DevTools → Console**

There should be no unexpected JavaScript errors.

Remember: you aren't using JavaScript yet.

# ♿ Accessibility Test

Try navigating your entire website using only your keyboard.

Use:

```text
Tab
Shift + Tab
Enter
```

Make sure:

- Links can receive focus.
    
- Links can be activated.
    
- Form controls can receive focus.
    
- FAQ controls can be operated.
    
- The page has a logical heading structure.
    

---

# 🖥️ Browser Testing

Test the website in your browser at different viewport sizes.

You don't need to make it responsive yet—that comes later with CSS.

For now, you're checking that:

- Content isn't accidentally missing.
    
- Links work.
    
- Images load.
    
- Text is readable.
    
- HTML structure behaves correctly.

# 10 - Multi-Page Personal Website

## 📌 Project Overview

This project is the tenth and final project in the **HTML Fundamentals** section of my frontend development learning journey.

The goal of this project is to combine the HTML concepts learned throughout the previous projects into a complete multi-page personal website.

Instead of creating one isolated HTML page, this project contains several connected pages with internal navigation.

The website introduces me, provides information about my background and skills, displays my projects, contains a blog section, and provides a contact page.

The project is intentionally built using **HTML5 only**. CSS and JavaScript will be introduced later in the learning roadmap.

---

## 🎯 Project Goals

The main goals of this project are:

- Build a complete multi-page website.
    
- Practice creating multiple HTML documents.
    
- Connect pages using internal links.
    
- Create consistent navigation across pages.
    
- Practice semantic HTML.
    
- Reuse concepts from previous projects.
    
- Practice organizing larger amounts of content.
    
- Create a personal website structure.
    
- Practice accessible HTML.
    
- Test navigation and links.
    
- Understand relative file paths.
    
- Strengthen HTML fundamentals before moving to CSS.
    

---

## 🛠 Technologies Used

- HTML5
    
- Browser Developer Tools
    
- Git
    
- GitHub
    

No CSS or JavaScript is used in this project.

---

A website is not necessarily a single HTML document.

- Consistent structure.
    
- Good accessibility.
