## 🧱 HTML Concepts Practiced

### HTML5 Document Structure

The project uses the standard HTML5 document structure:

```html
<!DOCTYPE html>
<html>
<head>
    ...
</head>
<body>
    ...
</body>
</html>
```

This provides the basic structure required for a webpage.

---

### Semantic HTML

The project uses semantic HTML elements including:

```html
<header>
<main>
<section>
<footer>
```

These elements describe the purpose of different parts of the webpage.

Semantic HTML makes the document easier for developers, browsers, search engines, and assistive technologies to understand.

---

### Headings

The page uses headings to organize content.

The main page title uses:

```html
<h1>
```

Individual sections use:

```html
<h2>
```

This creates a clear content hierarchy.

---

### Paragraphs

Paragraphs are created using:

```html
<p>
```

They are used for longer descriptions and personal information.

---

### Images

The page includes a profile image using:

```html
<img>
```

The image includes alternative text using the `alt` attribute.

Example:

```html
<img
    src="profile.jpg"
    alt="Profile picture of Abolfazl Asadi"
>
```

The `alt` attribute improves accessibility and provides a description if the image cannot be displayed.

---

### Unordered Lists

Unordered lists are used when the order of items does not matter.

Example:

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

---

### Ordered Lists

Ordered lists are used when the order of the items is meaningful.

Example:

```html
<ol>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
    <li>Learn JavaScript</li>
</ol>
```

This project provides practice with both `<ul>` and `<ol>`.

---

### Links

The project includes an external link to GitHub using:

```html
<a href="https://github.com/abolfazlasadiev-hash">
    GitHub
</a>
```

The link uses `target="_blank"` to open the external page in a new browser tab.

---

### Strong Text

The `<strong>` element is used to give important text semantic emphasis.

Example:

```html
<strong>HTML</strong>
```

This indicates that the text is important rather than simply making it visually bold.
