# 1. Header

Start with your name and professional direction.

```html
<header>
    <h1>Abolfazl Asadi</h1>
    <p>Frontend Development Learner</p>

    <address>
        <p>Email: your-email@example.com</p>
        <p>GitHub:
            <a href="https://github.com/abolfazlasadiev-hash">
                github.com/abolfazlasadiev-hash
            </a>
        </p>
    </address>
</header>
```

### New concept: `<address>`

`<address>` is useful for contact information associated with the person or organization represented by the page.

---

# 2. Professional Summary

Write a short professional introduction.

```html
<section>
    <h2>Professional Summary</h2>

    <p>
        Frontend development learner focused on building a strong
        foundation in HTML, CSS, and JavaScript through practical
        projects and continuous learning.
    </p>
</section>
```

Keep this section short—around 2–4 sentences.

---

# 3. Education

Use a section for your educational background.

```html
<section>
    <h2>Education</h2>

    <article>
        <h3>Degree or Program Name</h3>
        <p>University or Institution Name</p>
        <p>2022 - 2026</p>
    </article>
</section>
```

If you have multiple educational experiences, create multiple `<article>` elements.

---

# 4. Skills

Use an unordered list:

```html
<section>
    <h2>Skills</h2>

    <ul>
        <li>HTML5</li>
        <li>CSS3</li>
        <li>JavaScript</li>
        <li>Git</li>
        <li>GitHub</li>
    </ul>
</section>
```

Don't claim skills you don't actually have. Since this is your learning roadmap, you can distinguish between **learning** and **proficient** skills.

For example:

```html
<li>HTML5 — Currently learning</li>
```

---

# 5. Work Experience

If you have work experience, include it.

```html
<section>
    <h2>Work Experience</h2>

    <article>
        <h3>Job Title</h3>
        <p>Company Name</p>
        <p>2024 - Present</p>

        <ul>
            <li>Responsibility or achievement.</li>
            <li>Responsibility or achievement.</li>
            <li>Responsibility or achievement.</li>
        </ul>
    </article>
</section>
```

### If you don't have work experience

That's completely fine.

You can write:

```html
<section>
    <h2>Work Experience</h2>

    <p>
        I am currently focused on developing my frontend development
        skills through personal projects and structured learning.
    </p>
</section>
```

**Don't invent jobs or experience.**

# 🧠 New HTML Concepts

Project #3 should introduce you to a few things you haven't used much in Projects 1 and 2.

### `<address>`

For contact information.

### `<article>`

For an independent piece of content, such as:

- A job
    
- An education entry
    
- A project
    

### `<time>`

You can also experiment with dates:

```html
<time datetime="2026">2026</time>
```

Or:

```html
<time datetime="2024-01">January 2024</time>
```

### `<abbr>`

You can practice abbreviations:

```html
<abbr title="HyperText Markup Language">HTML</abbr>
```

These aren't mandatory, but they're good HTML practice.

## 📌 Project Overview

The **Resume Page** is the third project in my frontend development learning roadmap.

The purpose of this project is to practice HTML5 by creating a structured personal resume webpage.

Unlike the previous projects, which focused primarily on personal introductions and general information, this project focuses on presenting information in a more professional and organized format.

The webpage represents a digital version of a resume/CV and contains sections for professional information, education, skills, experience, projects, certifications, languages, and interests.

This project is intentionally built using **HTML5 only**. CSS and JavaScript are not used because the current stage of the roadmap focuses on understanding HTML structure and semantic elements.

# 🧱 Semantic HTML

This project provides additional practice with semantic HTML.

Important elements include:

### `<header>`

Used for introductory content and contact information.

### `<main>`

Contains the primary resume content.

### `<section>`

Groups related information such as education, skills, and projects.

### `<article>`

Used for individual entries such as:

- A job
    
- A project
    
- An education record
    

### `<address>`

Used for contact information.

### `<footer>`

Contains footer information.

Using semantic HTML makes the structure easier for browsers, search engines, assistive technologies, and other developers to understand.
