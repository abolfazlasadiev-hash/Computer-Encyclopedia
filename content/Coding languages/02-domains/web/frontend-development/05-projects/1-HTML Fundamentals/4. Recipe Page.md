# 🧠 What You Will Learn

This project introduces several useful HTML elements.

### Lists

Ingredients are perfect for an unordered list:

```html
<ul>
    <li>2 eggs</li>
    <li>1 cup flour</li>
    <li>1 cup milk</li>
</ul>
```

Instructions are naturally represented by an ordered list:

```html
<ol>
    <li>Mix the ingredients.</li>
    <li>Heat the pan.</li>
    <li>Cook for 5 minutes.</li>
</ol>
```

### `<article>`

A recipe can be treated as a self-contained piece of content:

```html
<article>
    <h1>Chocolate Pancakes</h1>
    ...
</article>
```

### `<figure>` and `<figcaption>`

Useful for recipe images:

```html
<figure>
    <img src="recipe.jpg" alt="Chocolate pancakes">
    <figcaption>Homemade chocolate pancakes</figcaption>
</figure>
```

### `<time>`

Useful for preparation and cooking durations:

```html
<p>Preparation time: <time datetime="PT10M">10 minutes</time></p>
```

### `<strong>`

Useful when information has particular importance:

```html
<p><strong>Important:</strong> Do not overcook the pancakes.</p>
```

# 💻 Example `index.html`

Use this as a starting point, but **change the recipe and content to your own choice**.

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Chocolate Pancakes Recipe</title>
</head>

<body>

    <header>
        <h1>Chocolate Pancakes</h1>

        <p>
            A simple and delicious recipe for homemade chocolate pancakes.
        </p>
    </header>

    <main>

        <article>

            <section>
                <h2>About This Recipe</h2>

                <figure>
                    <img
                        src="recipe.jpg"
                        alt="Stack of homemade chocolate pancakes"
                        width="400"
                    >

                    <figcaption>
                        Homemade chocolate pancakes.
                    </figcaption>
                </figure>

                <p>
                    These chocolate pancakes are easy to prepare and are
                    perfect for breakfast or a weekend treat.
                </p>
            </section>


            <section>
                <h2>Recipe Information</h2>

                <ul>
                    <li>
                        Preparation time:
                        <time datetime="PT10M">10 minutes</time>
                    </li>

                    <li>
                        Cooking time:
                        <time datetime="PT15M">15 minutes</time>
                    </li>

                    <li>Servings: 4 people</li>

                    <li>Difficulty: Easy</li>
                </ul>
            </section>


            <section>
                <h2>Ingredients</h2>

                <ul>
                    <li>2 cups all-purpose flour</li>
                    <li>2 tablespoons cocoa powder</li>
                    <li>2 tablespoons sugar</li>
                    <li>1 teaspoon baking powder</li>
                    <li>2 eggs</li>
                    <li>1½ cups milk</li>
                    <li>2 tablespoons melted butter</li>
                    <li>1 teaspoon vanilla extract</li>
                    <li>A pinch of salt</li>
                </ul>
            </section>


            <section>
                <h2>Instructions</h2>

                <ol>
                    <li>
                        In a large bowl, combine the flour, cocoa powder,
                        sugar, baking powder, and salt.
                    </li>

                    <li>
                        In another bowl, whisk together the eggs, milk,
                        melted butter, and vanilla extract.
                    </li>

                    <li>
                        Pour the wet ingredients into the dry ingredients.
                    </li>

                    <li>
                        Mix until the ingredients are combined.
                        Do not overmix the batter.
                    </li>

                    <li>
                        Heat a pan over medium heat.
                    </li>

                    <li>
                        Pour a small amount of batter into the pan.
                    </li>

                    <li>
                        Cook until bubbles appear on the surface,
                        then flip the pancake.
                    </li>

                    <li>
                        Cook the other side until golden brown.
                    </li>

                    <li>
                        Repeat until all the batter has been used.
                    </li>
                </ol>
            </section>


            <section>
                <h2>Serving Suggestions</h2>

                <p>
                    Serve the pancakes with fresh fruit, honey,
                    chocolate sauce, or your favorite toppings.
                </p>
            </section>


            <section>
                <h2>Tips</h2>

                <p>
                    <strong>Tip:</strong>
                    Avoid mixing the batter too much because this can
                    make the pancakes less fluffy.
                </p>
            </section>


            <section>
                <h2>Nutrition Information</h2>

                <p>
                    Approximate calories per serving: 350 calories.
                </p>
            </section>

        </article>

    </main>


    <footer>
        <p>&copy; 2026 Abolfazl Asadi</p>
    </footer>

</body>

</html>
```

## 📖 Overview

The **Recipe Page** is the fourth project in my frontend development learning journey.

The purpose of this project is to practice building a structured, readable, and semantic webpage using **HTML5 only**.

The page presents a complete recipe including the recipe title, image, description, preparation information, ingredients, cooking instructions, serving suggestions, tips, and nutrition information.

This project focuses on organizing different types of content correctly using HTML elements rather than focusing on visual styling.

## 🍽️ Page Content

The recipe page contains several sections.

### 1. Recipe Header

The header introduces the recipe with:

- Recipe name
    
- Short description
    

Example:

```html
<header>
    <h1>Chocolate Pancakes</h1>
    <p>A simple and delicious recipe for homemade chocolate pancakes.</p>
</header>
```

---

### 2. Recipe Image

The page contains an image representing the recipe.

The image is placed inside a `<figure>` element with a `<figcaption>`.

```html
<figure>
    <img
        src="recipe.jpg"
        alt="Stack of homemade chocolate pancakes"
    >

    <figcaption>
        Homemade chocolate pancakes.
    </figcaption>
</figure>
```

This helps practice meaningful image descriptions and semantic HTML.

---

### 3. Recipe Information

Basic information about the recipe is displayed, such as:

- Preparation time
    
- Cooking time
    
- Servings
    
- Difficulty
    

The `<time>` element can be used to represent preparation and cooking times.

```html
<time datetime="PT10M">10 minutes</time>
```

---

### 4. Ingredients

Ingredients are represented using an unordered list.

```html
<ul>
    <li>2 eggs</li>
    <li>1 cup flour</li>
    <li>1 cup milk</li>
</ul>
```

An unordered list is appropriate because the ingredients do not need to be followed in a specific sequence.

---

### 5. Instructions

Cooking instructions are represented using an ordered list.

```html
<ol>
    <li>Prepare the ingredients.</li>
    <li>Mix the ingredients.</li>
    <li>Heat the pan.</li>
    <li>Cook the recipe.</li>
</ol>
```

An ordered list is appropriate because the steps should be followed in sequence.

---

### 6. Serving Suggestions

This section explains how the finished food can be served.

Examples include:

- Suggested toppings
    
- Side dishes
    
- Sauces
    
- Drinks
    

---

### 7. Cooking Tips

The page can contain useful tips for preparing the recipe.

Important information can be emphasized with `<strong>`.

```html
<p>
    <strong>Tip:</strong>
    Avoid overmixing the batter.
</p>
```

---

### 8. Nutrition Information

The page may contain basic nutritional information such as approximate calories per serving.

This section is included mainly to practice organizing additional recipe information.

## 🔍 Testing

The page should be tested in a modern web browser.

### HTML Structure

Check that:

- The document has `<!DOCTYPE html>`.
    
- The `<html>` element has a language attribute.
    
- The `<head>` contains the character encoding.
    
- The viewport is configured.
    
- The page has a meaningful `<title>`.
    
- The body contains a logical structure.
    

### Accessibility

Check that:

- Images have meaningful `alt` text.
    
- Headings follow a logical hierarchy.
    
- Lists are used appropriately.
    
- Content is understandable without CSS.
    

### Browser Testing
