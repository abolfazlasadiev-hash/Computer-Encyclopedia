# 🧠 Important: Why `<dl>`?

This is one of the most useful new concepts in Project 6.

You might be tempted to write:

```html
<ul>
    <li>Processor: Intel Core i7</li>
    <li>Memory: 16 GB</li>
    <li>Storage: 512 GB SSD</li>
</ul>
```

That works, but HTML has a better semantic structure for **term → description/value** relationships:

```html
<dl>

    <dt>Processor</dt>
    <dd>Intel Core i7</dd>

    <dt>Memory</dt>
    <dd>16 GB</dd>

    <dt>Storage</dt>
    <dd>512 GB SSD</dd>

</dl>
```

Think:

```text
<dl> = description list
<dt> = description term
<dd> = description/details
```

This is perfect for product specifications.

---

# ⭐ Another Important Concept: Nested Articles

Notice the reviews:

```html
<article>

    <h3>Excellent for Development</h3>

    <p>...</p>

</article>
```

A product is an article, but each review can also be treated as its own independent piece of content.

So you can have:

```text
<article>
    Product
    │
    ├── <section>
    │
    ├── <section>
    │
    └── Reviews
        │
        ├── <article>
        └── <article>
</article>
```

This is good practice for understanding nested semantic structures.

## 📖 Overview

The **Product Information Page** is the sixth project in my frontend development learning journey.

The purpose of this project is to practice creating a realistic product information webpage using **HTML5 only**.

The page presents a product with its name, image, description, price, availability, features, specifications, available options, included items, customer reviews, shipping information, and support information.

This project focuses on semantic HTML and organizing product information in a clear and meaningful structure.

No CSS or JavaScript is used.
