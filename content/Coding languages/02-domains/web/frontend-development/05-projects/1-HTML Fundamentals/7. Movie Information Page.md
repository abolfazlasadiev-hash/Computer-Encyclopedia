# 🧠 Important New Concept: `<dl>`

Project 6 introduced description lists, and Project 7 gives you another excellent opportunity to use them.

Movie metadata is naturally represented as:

```html
<dl>

    <dt>Director</dt>
    <dd>Christopher Nolan</dd>

    <dt>Genre</dt>
    <dd>Science Fiction</dd>

    <dt>Runtime</dt>
    <dd>2 hours 49 minutes</dd>

    <dt>Language</dt>
    <dd>English</dd>

</dl>
```

Think of it as:

```text
Term       → Value
---------------------------
Director   → Person
Genre      → Category
Runtime    → Duration
Language   → Language
```

This is much more meaningful than putting everything into random paragraphs.

### 3. Movie Poster

The movie poster is represented using an image inside a `<figure>` element.

```html

    </figcaption>
```

### 4. Movie Information

The page contains basic movie metadata such as:

- Genre
    
- Runtime
    
- Language
    
- Age rating
    
- Audience rating
    

This information is represented using a description list.

```html
<dl>

    <dt>Genre</dt>
    <dd>Science Fiction</dd>

    <dt>Runtime</dt>
    <dd>2 hours 18 minutes</dd>

    <dt>Language</dt>
    <dd>English</dd>

</dl>
```

---

### 6. Director

The director of the movie is displayed in its own section.

---

### 7. Main Cast

The main actors and their characters are displayed using an unordered list.

```html
<ul>
    <li>Actor One as Character One</li>
    <li>Actor Two as Character Two</li>
    <li>Actor Three as Character Three</li>
</ul>
```

The page contains a link to the movie trailer.

External links can use:

```html
target="_blank"
rel="noopener noreferrer"
```

when they are intended to open in a new browser tab.

Awards and achievements can be represented using an unordered list.

- Best Director
