# 🔍 Important Things to Understand

## 1. Why use `<label>`?

This:

```html
<label for="email">Email Address:</label>
<input type="email" id="email" name="email">
```

is better than simply writing:

```html
Email:
<input type="email">
```

because the label is explicitly associated with the input.

You can also click the label to focus the corresponding input.

---

## 2. Why do inputs need `name`?

For example:

```html
<input type="text" id="name" name="name">
```

The `id` identifies the element in the document.

The `name` identifies the form field when form data is submitted.

Think of them as having different purposes.

---

## 3. Why do radio buttons share the same `name`?

These:

```html
<input type="radio" name="contact-method" value="email">
<input type="radio" name="contact-method" value="github">
```

belong to the same group because they have the same `name`.

That allows the user to select **one** option.

---

## 4. What does `required` do?

```html
<input type="email" required>
```

The browser won't allow the form to be submitted normally until that field has a value.

This gives you your first introduction to **native HTML form validation**, without JavaScript.

---

## 5. What is `<fieldset>`?

Instead of putting every form element directly inside `<form>`, we can group related fields:

```html
<fieldset>
    <legend>Personal Information</legend>

    ...
</fieldset>
```

This gives the form meaningful structure.
