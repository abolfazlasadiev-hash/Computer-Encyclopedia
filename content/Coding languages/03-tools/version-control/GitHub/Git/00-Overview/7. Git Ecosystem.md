The **Git ecosystem** is the collection of tools, platforms, services, workflows, and technologies built around **Git**.

Git itself focuses on version control, but modern software development often involves many additional tools.

> **The Git ecosystem extends Git from a local version-control tool into a complete collaboration and software-development environment.**

# 4. Remote Repositories

Git can communicate with other repositories called **remotes**.

A common remote is named:

```text
origin
```

Example:

```text
Local Repository
       │
       │ git push
       ▼
Remote Repository
       │
       └── GitHub / GitLab / Bitbucket
```

You can list remotes using:

```bash
git remote
```

View detailed remote information:

```bash
git remote -v
```

# 11. Git LFS

Git is excellent for source code and text-based files.

Large binary files can create challenges because repository history may grow significantly.

**Git LFS (Large File Storage)** helps manage certain large files separately.

```text
Repository
│
├── Source Code
│
└── Large Files
     │
     ▼
   Git LFS
```

Git LFS commonly uses small pointer files in the Git repository while storing the actual large content through an LFS storage system.

It is often used for:

- Large media files
    
- Design assets
    
- Game assets
    
- Large datasets

# 18. Git Ecosystem vs Git Itself

This distinction is important.

```text
Git
│
├── Version Control
├── Commits
├── Branches
└── History
```

The broader ecosystem:

```text
Git Ecosystem
│
├── Git
├── Hosting Platforms
├── Collaboration
├── Code Review
├── CI/CD
├── GUI Tools
├── IDE Integration
├── Security
├── Package Registries
└── Development Workflows
```

> **Git is the foundation. The Git ecosystem is everything that helps developers host, collaborate, automate, secure, and manage software around Git repositories.**
