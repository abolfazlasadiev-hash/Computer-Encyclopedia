# 🔍 Understanding `CREATE DATABASE`

The basic syntax is:

```sql
CREATE DATABASE database_name;
```

For your project:

```sql
CREATE DATABASE learning_journey;
```

### What each part means

```text
CREATE
   ↓
Tell SQL that you want to create something

DATABASE
   ↓
The thing you want to create is a database

learning_journey
   ↓
The name of your database
```

So:

```sql
CREATE DATABASE learning_journey;
```

means:

> Create a database called `learning_journey`.

---

# 🔍 Understanding `USE`

After creating the database:

```sql
USE learning_journey;
```

This tells SQL:

> I want to work inside the `learning_journey` database.

For example, later you might write:

```sql
CREATE TABLE users (
    id INT,
    name VARCHAR(100)
);
```

Because you previously wrote:

```sql
USE learning_journey;
```

the `users` table will be created inside:

```text
learning_journey
```

# ⚠️ Important: Running the Script Twice

If you run:

```sql
CREATE DATABASE learning_journey;
```

again, you may receive an error because the database already exists.

You can use:

```sql
CREATE DATABASE IF NOT EXISTS learning_journey;
```

This is safer for practice.

Your final version could therefore be:

```sql
-- Create the database
CREATE DATABASE IF NOT EXISTS learning_journey;

-- Select the database
USE learning_journey;

-- Verify available databases
SHOW DATABASES;
```

For a beginner, I recommend using `IF NOT EXISTS` because you can execute the script multiple times without getting the "database already exists" error.

# 🔄 Difference Between a Database and a Table

A database is a container that can hold tables and other database objects.

For example:

```text
Database
│
└── learning_journey
        │
        ├── users
        ├── projects
        ├── skills
        └── progress
```

A table stores structured data.

For example, a future `users` table could contain:

```text
users
────────────────────────
id | name | email
────────────────────────
1  | Ali  | ali@example.com
2  | Sara | sara@example.com
```

However, tables are intentionally not part of this project.
