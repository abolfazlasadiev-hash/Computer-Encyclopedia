# 🪜 Step 1 — Select User Information

Start with a simple user directory.

```sql
USE learning_journey;

SELECT
    name,
    email,
    age,
    country
FROM users;
```

This produces a report containing basic information about every user.

---

# 🪜 Step 2 — Filter the Report

Now suppose we only want users who are at least 25.

```sql
SELECT
    name,
    email,
    age,
    country
FROM users
WHERE age >= 25;
```

The important part is:

```sql
WHERE age >= 25
```

It removes users who don't match the condition from the result.

---

# 🪜 Step 3 — Sort the Report

Now let's make the report easier to read by sorting users from oldest to youngest.

```sql
SELECT
    name,
    email,
    age,
    country
FROM users
ORDER BY age DESC;
```

`DESC` means:

```text
Highest → Lowest
```

So the oldest users appear first.

---

# 🪜 Step 4 — Create a Filtered + Sorted Report

Now combine `WHERE` and `ORDER BY`.

```sql
SELECT
    name,
    email,
    age,
    country
FROM users
WHERE age >= 25
ORDER BY age DESC;
```

Read this like English:

> Select user information from users where the age is at least 25, then order the results from oldest to youngest.

This is where SQL starts becoming much more useful.

---

# 🪜 Step 5 — Show Only the Top 3

Now let's say a manager only wants the **3 oldest users who are at least 25**.

```sql
SELECT
    name,
    email,
    age,
    country
FROM users
WHERE age >= 25
ORDER BY age DESC
LIMIT 3;
```

This combines three concepts:

```text
WHERE
↓
Filter users

ORDER BY
↓
Sort users

LIMIT
↓
Keep only the first 3 results
```

# ⚠️ Common Beginner Mistakes

### 1. Forgetting `FROM`

❌

```sql
SELECT name, age;
```

✅

```sql
SELECT name, age
FROM users;
```

---

### 2. Putting clauses in the wrong order

❌

```sql
SELECT *
FROM users
LIMIT 3
ORDER BY age DESC;
```

✅

```sql
SELECT *
FROM users
ORDER BY age DESC
LIMIT 3;
```

For the queries you've learned so far, remember:

```text
SELECT
FROM
WHERE
ORDER BY
LIMIT
```

---

### 3. Using `LIMIT` without `ORDER BY`

This:

```sql
SELECT *
FROM users
LIMIT 3;
```

returns 3 rows, but doesn't define which 3 users should be considered the "top" 3.

For predictable results, use:

```sql
ORDER BY ...
LIMIT ...
```

---

### 4. Using `=` incorrectly

Text values need quotes:

```sql
WHERE country = 'Iran';
```

Numbers don't normally need quotes:

```sql
WHERE age >= 25;
```

# ⚠️ Common Beginner Mistakes

## Forgetting FROM

Incorrect:

```sql
SELECT name, age;
```

Correct:

```sql
SELECT name, age
FROM users;
```

---

## Incorrect Clause Order

Incorrect:

```sql
SELECT *
FROM users
LIMIT 3
ORDER BY age DESC;
```

Correct:

```sql
SELECT *
FROM users
ORDER BY age DESC
LIMIT 3;
```

---

## Forgetting Quotes Around Text

Correct:

```sql
WHERE country = 'Iran';
```

For numeric comparisons:

```sql
WHERE age >= 25;
```

---

## Using LIMIT Without ORDER BY

`LIMIT` restricts the number of returned rows, but without `ORDER BY`, it does not define which rows are the "top" rows.

For predictable top-N reports, use:

```sql
ORDER BY ...
LIMIT ...
```
