# 🧠 Understanding `CREATE TABLE`

The basic syntax is:

```sql
CREATE TABLE table_name (
    column_name data_type,
    column_name data_type,
    column_name data_type
);
```

Your example:

```sql
CREATE TABLE users (
    id INT,
    name VARCHAR(100),
    email VARCHAR(150),
    age INT,
    country VARCHAR(100)
);
```

Think of it like designing an empty spreadsheet.

```text
users
┌────┬────────┬──────────────┬─────┬─────────┐
│ id │ name   │ email        │ age │ country │
├────┼────────┼──────────────┼─────┼─────────┤
│    │        │              │     │         │
│    │        │              │     │         │
│    │        │              │     │         │
└────┴────────┴──────────────┴─────┴─────────┘
```

You have created the **structure**, but there is no data yet.

# 🧠 Important Difference

There is an important difference between these two commands:

```sql
CREATE TABLE users (...);
```

and:

```sql
INSERT INTO users (...);
```

`CREATE TABLE` defines the **structure**.

```text
CREATE TABLE
      ↓
"What columns should this table have?"
```

`INSERT` adds **data**.

```text
INSERT
  ↓
"What information should I store?"
```

Your current project is only:

```text
Database
   ↓
Create Table
   ↓
Define Columns
```

Project #3 will be:

```text
Database
   ↓
Users Table
   ↓
Insert Users
```
