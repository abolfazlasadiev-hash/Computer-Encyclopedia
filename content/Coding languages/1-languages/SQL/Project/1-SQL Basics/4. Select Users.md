# 📌 Column Order Matters

If you write:

```sql

FROM users;
```


If you write:

The table itself hasn't changed.

You're only changing the order of the columns in the query result.

# 🧱 SQL Concepts Practiced

## SELECT

The `SELECT` statement is used to retrieve data from a database.

Example:

```sql
SELECT name
FROM users;
```

This retrieves the `name` column from every row in the `users` table.

---

## FROM

The `FROM` clause specifies the table from which the data should be retrieved.

Example:

```sql
SELECT name
FROM users;
```

The database reads:

```text
SELECT
   ↓
What information?

name
   ↓
FROM
   ↓
Which table?

users
```

---

## SELECT *

The asterisk `*` means all columns.

Example:

```sql
SELECT * FROM users;
```

This retrieves every column and every row from the table.

---

## Selecting One Column

A single column can be selected:

```sql
SELECT name
FROM users;
```

The result contains only the names.

Another example:

```sql
SELECT email
FROM users;
```

This returns only email addresses.

---

## Selecting Multiple Columns

Multiple columns can be selected by separating their names with commas:

```sql
SELECT name, email, age
FROM users;
```

The result contains:

```text
name
email
age
```

---

# 🔍 Column Order

The order of columns in the `SELECT` statement controls the order of the result.

For example:

```sql
SELECT name, age, country
FROM users;
```

returns:

```text
name | age | country
```

While:

```sql
SELECT country, name, age
FROM users;
```

returns:

```text
country | name | age
```

The actual table structure is not changed.

Only the query result changes.
