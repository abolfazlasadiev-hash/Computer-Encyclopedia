# 🧠 What You Will Learn

The main concept is:

```sql
WHERE
```

It allows you to tell SQL:

> "Give me only the rows where this condition is true."

For example:

```sql
SELECT *
FROM users
WHERE age > 25;
```

SQL checks every user:

```text
Abolfazl → 25 > 25 ❌
Sara     → 24 > 25 ❌
Daniel   → 29 > 25 ✅
Emma     → 27 > 25 ✅
Alex     → 31 > 25 ✅
```

So SQL returns only:

```text
Daniel
Emma
Alex
```

---

# 🧩 Basic Filtering Syntax

The general structure is:

```sql
SELECT columns
FROM table
WHERE condition;
```

For example:

```sql
SELECT *
FROM users
WHERE age > 25;
```

Think about it like this:

```text
SELECT
   ↓
What do I want?

FROM
   ↓
Which table?

WHERE
   ↓
Which rows?
```

# 🧠 7. Filtering Text vs Numbers

This is important.

### Numbers

Don't use quotes:

```sql
WHERE age > 25
```

### Text

Use quotes:

```sql
WHERE country = 'Iran'
```

Correct:

```sql
WHERE age = 25
```

Correct:

```sql
WHERE name = 'Abolfazl Asadi'
```

Don't write:

```sql
WHERE age = '25'
```

when you're practicing basic numeric comparisons.

## 🎯 Project Goal

The goal of this project is to learn how to filter database records using the SQL `WHERE` clause.

Instead of displaying every record in a table, `WHERE` allows us to retrieve only the records that satisfy a specific condition.

Examples include:

- Finding users older than a certain age
    
- Finding users from a specific country
    
- Finding users younger than a certain age
    
- Finding users with an exact value
    
- Excluding users with a specific value
