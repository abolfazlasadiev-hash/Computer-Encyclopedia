# 🧠 What You Will Learn

The main concept is:

```sql
ORDER BY
```

It tells SQL:

> "After finding my results, put them in this order."

Basic syntax:

```sql
SELECT columns
FROM table
ORDER BY column;
```

For example:

```sql
SELECT *
FROM users
ORDER BY age;
```

This sorts users by age from **smallest to largest**.

---

# 🔼 1. Ascending Order

Ascending means:

> Small → Large

For numbers:

```text
20
25
27
29
31
```

For text:

```text
Alex
Daniel
Emma
Sara
```

SQL uses:

```sql
ASC
```

Example:

```sql
SELECT *
FROM users
ORDER BY age ASC;
```

`ASC` means **ascending**.

---

# 🔽 2. Descending Order

Descending means:

> Large → Small

For numbers:

```text
31
29
27
25
24
```

SQL uses:

```sql
DESC
```

Example:

```sql
SELECT *
FROM users
ORDER BY age DESC;
```

`DESC` means **descending**.

---

# 💡 Important: ASC Is the Default

You can write:

```sql
SELECT *
FROM users
ORDER BY age;
```

This normally behaves like:

```sql
SELECT *
FROM users
ORDER BY age ASC;
```

So these are equivalent:

```sql
ORDER BY age;
```

and:

```sql
ORDER BY age ASC;
```

For learning, I recommend writing `ASC` explicitly so you become familiar with it.

---

# 🔤 3. Sort Users by Name

You can sort text columns too.

```sql
SELECT *
FROM users
ORDER BY name ASC;
```

This organizes the names alphabetically.

For example:

```text
Alex Wilson
Abolfazl Asadi
Daniel Smith
Emma Brown
Sara Johnson
```

The exact ordering can depend on your database's collation, but the important idea is:

> SQL can sort text as well as numbers.

---

# 🔤 4. Reverse Alphabetical Order

Use `DESC`:

```sql
SELECT *
FROM users
ORDER BY name DESC;
```

Now the names are ordered in reverse.

---

# 🌍 5. Sort by Country

You can sort any column.

```sql
SELECT *
FROM users
ORDER BY country ASC;
```

Or:

```sql
SELECT *
FROM users
ORDER BY country DESC;
```

# 🔎 6. Combine WHERE + ORDER BY

This is an important step.

You already learned:

```sql
WHERE
```

Now you can combine it with:

```sql
ORDER BY
```

For example:

> Show users older than 25, starting with the oldest.

```sql
SELECT *
FROM users
WHERE age > 25
ORDER BY age DESC;
```

The SQL process is conceptually:

```text
users
  ↓
WHERE age > 25
  ↓
keep matching users
  ↓
ORDER BY age DESC
  ↓
sort them from oldest to youngest
```

This is a very useful pattern in real SQL.

---

# 🧠 SQL Clause Order

You will start seeing SQL queries with multiple clauses.

For this project, remember:

```sql
SELECT
FROM
WHERE
ORDER BY
```

Example:

```sql
SELECT name, age, country
FROM users
WHERE age >= 25
ORDER BY age DESC;
```

Read it as:

> Select the name, age, and country from users where the age is at least 25, and order the results from oldest to youngest.

---

# 🔢 7. Sort Only Specific Columns

You don't have to display every column.

This gives you a simple age list:

# 🧩 8. Sort by Multiple Columns

You can eventually sort by more than one column.

For example:

```sql

FROM users

```

This means:

1. Sort by country alphabetically.
    
2. If multiple users have the same country, sort those users by age from oldest to youngest.
    

However, **don't make this the main focus yet**.

Your primary goal in Project #6 is understanding:


and:

```sql

```

# 🧠 WHERE vs ORDER BY

This distinction is extremely important.

### `WHERE`

Answers:

> **Which records should I get?**

Example:

```sql
WHERE age > 25
```

### `ORDER BY`

Answers:

> **In what order should I see them?**

Example:

```sql
ORDER BY age DESC
```

Together:

```sql
SELECT *
FROM users
WHERE age > 25
ORDER BY age DESC;
```

Means:

> Give me users older than 25, starting with the oldest.

# ⚠️ Common Beginner Mistakes

### Mistake 1 — Putting `ORDER BY` before `WHERE`

Wrong:

```sql
SELECT *
FROM users
ORDER BY age DESC
WHERE age > 25;
```

Correct:

```sql
SELECT *
FROM users
WHERE age > 25
ORDER BY age DESC;
```

The order matters.

---

### Mistake 2 — Forgetting `DESC`

This:

```sql
ORDER BY age;
```

does **not** mean oldest first.

For oldest first, use:

```sql
ORDER BY age DESC;
```

---

### Mistake 3 — Sorting Doesn't Change the Database

This:

```sql
SELECT *
FROM users
ORDER BY age DESC;
```

does **not** permanently rearrange your table.

It only changes the order of the results returned by that query.

Your actual stored data remains unchanged.

```sql
SELECT columns
```

---

## 🔼 Ascending Order

Ascending order goes from smaller to larger or from earlier alphabetically to later alphabetically.

```sql
SELECT *
FROM users
ORDER BY age ASC;
```

## 🔽 Descending Order

Descending order goes from larger to smaller or from later alphabetically to earlier alphabetically.

```sql
SELECT *
FROM users
ORDER BY age DESC;
```

`DESC` means descending.
