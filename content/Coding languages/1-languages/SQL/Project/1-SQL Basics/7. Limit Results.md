# 🧠 What You Will Learn

The main concept is:

```sql
LIMIT
```

It tells SQL:

> "Return only this many rows."

Basic syntax:

```sql
SELECT columns
FROM table
LIMIT number;
```

For example:

```sql
SELECT *
FROM users
LIMIT 3;
```

If the table contains 5 users, SQL returns only 3 rows.

---

# 🔢 1. Limit the Number of Rows

Start with:

```sql
SELECT *
FROM users
LIMIT 3;
```

If your table contains:

```text
1 — Abolfazl Asadi
2 — Sara Johnson
3 — Daniel Smith
4 — Emma Brown
5 — Alex Wilson
```

the query returns 3 rows.

The important thing is:

```sql
LIMIT 3
```

means:

> Return no more than 3 rows.

---

# 🧠 LIMIT Does Not Delete Anything

This is very important.

When you write:

```sql
SELECT *
FROM users
LIMIT 3;
```

you are **not deleting** the other users.

The database still contains all the records.

You're simply saying:

> "For this query, show me only 3 rows."

So:

```text
Database:
5 users

       ↓

SELECT ... LIMIT 3

       ↓

Result:
3 users
```

The other 2 users are still stored in the table.

---

# 🔼 2. Sort + Limit

`LIMIT` becomes much more useful when combined with `ORDER BY`.

For example:

> Show the 3 youngest users.

```sql
SELECT *
FROM users
ORDER BY age ASC
LIMIT 3;
```

The process is:

```text
users
  ↓
ORDER BY age ASC
  ↓
youngest → oldest
  ↓
LIMIT 3
  ↓
first 3 users
```

With our sample data:

```text
Sara Johnson     24
Abolfazl Asadi   25
Emma Brown       27
```

---

# 🔽 3. Find the Oldest Users

To find the 2 oldest users:

```sql
SELECT *
FROM users
ORDER BY age DESC
LIMIT 2;
```

The database first sorts:

```text
31
29
27
25
24
```

Then:

```text
LIMIT 2
```

keeps only:

```text
31
29
```

So the result is:

```text
Alex Wilson
Daniel Smith
```

This pattern is extremely useful:

```sql
ORDER BY ... DESC
LIMIT ...
```

---

# 🔎 4. WHERE + ORDER BY + LIMIT

Now you can combine the three concepts you've learned.

Suppose you want:

> The 2 oldest users who are older than 25.

Write:

```sql
SELECT *
FROM users
WHERE age > 25
ORDER BY age DESC
LIMIT 2;
```

Think about the process:

```text
All users
   ↓
WHERE age > 25
   ↓
Only matching users
   ↓
ORDER BY age DESC
   ↓
Oldest first
   ↓
LIMIT 2
   ↓
Top 2 users
```

With our sample data:

```text
Alex Wilson      31
Daniel Smith     29
```

---

# 🧩 5. LIMIT With Specific Columns

You don't have to use:

```sql
SELECT *
```

You can choose specific columns:

```sql
SELECT name, age
FROM users
ORDER BY age DESC
LIMIT 3;
```

Result:

```text
Alex Wilson      31
Daniel Smith     29
Emma Brown       27
```

This combines the concepts from Projects #4 and #6 with `LIMIT`.

---

# 🧪 6. LIMIT With a Filter

For example:

> Show only the first 2 users from users younger than 30.

```sql
SELECT *
FROM users
WHERE age < 30
LIMIT 2;
```

Notice that without `ORDER BY`, you should **not assume which two rows are the "first"** in a meaningful business sense.

If you want a predictable result, combine `LIMIT` with `ORDER BY`.

For example:

```sql
SELECT *
FROM users
WHERE age < 30
ORDER BY age ASC
LIMIT 2;
```

Now you are explicitly asking for:

> The 2 youngest users who are younger than 30.

---

# ⭐ 7. Why ORDER BY + LIMIT Is Important

Consider:

```sql
SELECT *
FROM users
LIMIT 2;
```

This says:

> Give me 2 rows.

But it doesn't say:

> Which 2 are the most important?

Now compare:

```sql
SELECT *
FROM users
ORDER BY age DESC
LIMIT 2;
```

This says:

> Give me the 2 oldest users.

That's much more precise.

This pattern is commonly used for things such as:

```text
Top 10 products
Top 5 customers
Latest 10 orders
Oldest employees
Highest-priced products
Lowest-priced products
```

You'll use these ideas repeatedly as your SQL skills become more advanced.

# 🧠 WHERE vs ORDER BY vs LIMIT

You now have three very useful tools.

### `WHERE`

Controls **which rows** are included.

```sql
WHERE age > 25
```

> Only users older than 25.

### `ORDER BY`

Controls **the order**.

```sql
ORDER BY age DESC
```

> Oldest first.

### `LIMIT`

Controls **how many rows** are returned.

```sql
LIMIT 2
```

> Only 2 rows.

Together:

```sql
SELECT *
FROM users
WHERE age > 25
ORDER BY age DESC
LIMIT 2;
```

Means:

> Find users older than 25, put the oldest first, and show only the first 2.

# ⚠️ Common Beginner Mistakes

### Mistake 1 — Thinking LIMIT deletes data

Wrong idea:

```text
LIMIT 2
→ delete everything except 2 users
```

No.

It only limits the **query result**.

---

### Mistake 2 — Using LIMIT before ORDER BY

Don't write:

```sql
SELECT *
FROM users
LIMIT 2
ORDER BY age DESC;
```

Correct:

```sql
SELECT *
FROM users
ORDER BY age DESC
LIMIT 2;
```

---

### Mistake 3 — Assuming LIMIT alone gives a meaningful ranking

This:

```sql
SELECT *
FROM users
LIMIT 2;
```

means:

> Give me 2 rows.

It does **not** mean:

> Give me the 2 youngest users.

For that, write:

```sql
SELECT *
FROM users
ORDER BY age ASC
LIMIT 2;
```

## 🧠 Main SQL Concept

The main concept introduced in this project is:

```sql
LIMIT
```

`LIMIT` restricts the number of rows returned by a query.

Basic syntax:

```sql
SELECT columns
FROM table
LIMIT number;
```

Example:

```sql
SELECT *
FROM users
LIMIT 3;
```

This returns no more than 3 rows.

---

## 🔼 LIMIT With Ascending Order

To find the 3 youngest users:

```sql
SELECT *
FROM users
ORDER BY age ASC
LIMIT 3;
```

The results are sorted from youngest to oldest and then limited to 3 rows.

---

## 🔽 LIMIT With Descending Order

To find the 2 oldest users:

```sql
SELECT *
FROM users
ORDER BY age DESC
LIMIT 2;
```

The results are sorted from oldest to youngest and then limited to 2 rows.

---

## 🔎 WHERE + ORDER BY + LIMIT

The three concepts can be combined:

```sql
SELECT *
FROM users
WHERE age > 25
ORDER BY age DESC
LIMIT 2;
```

This query:

1. Selects data from `users`.
    
2. Keeps users older than 25.
    
3. Sorts them from oldest to youngest.
    
4. Returns only the first 2 users.
