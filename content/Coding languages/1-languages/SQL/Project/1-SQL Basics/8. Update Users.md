# 🧠 What You Will Learn

The main command is:

```sql
UPDATE
```

Basic syntax:

```sql
UPDATE table
SET column = new_value
WHERE condition;
```

For example:

```sql
UPDATE users
SET age = 26
WHERE id = 1;
```

Think of it as:

```text
UPDATE
   ↓
Which table?

SET
   ↓
What should change?

WHERE
   ↓
Which row(s)?
```

---

# ⚠️ Why WHERE Is Extremely Important

This is one of the most important lessons in this project.

You should normally identify **which record you want to update**.

For example:

```sql
UPDATE users
SET age = 26
WHERE id = 1;
```

The `WHERE` clause says:

> Only update the user whose ID is 1.

Without `WHERE`:

```sql
UPDATE users
SET age = 26;
```

you are asking SQL to change the age of **every user** to 26.

That can be disastrous in a real database.

So remember:

> **Always think carefully about your `WHERE` condition before running an `UPDATE`.**

# 🧩 5. Update Multiple Columns

You can change multiple columns in one query.

For example:

```sql

SET age = 28,
```

This changes both:


for user `id = 4`.

The syntax is:

```sql
SET column1 = value1,
    column2 = value2
```

You separate multiple assignments with commas.

# ⚠️ Important: Re-running UPDATE

There's an important difference between this project and Project #3.

If you run:

```sql
UPDATE users
SET age = 26
WHERE id = 1;
```

again, it doesn't create another user.

It simply sets that user's age to `26` again.

However, your script may become confusing if you use updates that depend on previous values.

For example:

```sql
UPDATE users
SET age = age + 1
WHERE id = 1;
```

If you run it once:

```text
26 → 27
```

Run it again:

```text
27 → 28
```

So be careful with updates that calculate values from existing data.

For this beginner project, direct assignments such as:

```sql
SET age = 26
```

are easier to understand.

# 🧠 Why IDs Are Useful

Suppose two users have the same name:

```text
John Smith
John Smith
```

If you write:

```sql
UPDATE users
SET age = 30
WHERE name = 'John Smith';
```

you might update multiple rows.

But if each user has a unique ID:

```sql
UPDATE users
SET age = 30
WHERE id = 7;
```

you can target one specific record.

You will formally learn **Primary Keys** later in Project #51, so don't add that concept to this project yet.

For now, simply practice using `id` as your row identifier.

## 🧠 Main SQL Concept

The main concept introduced in this project is:

```sql
UPDATE
```

`UPDATE` modifies existing rows in a table.

Basic syntax:

```sql
UPDATE table
SET column = value
WHERE condition;
```

Example:

```sql
UPDATE users
SET age = 26
WHERE id = 1;
```

This changes the age of the user whose ID is `1`.

---

## 🔍 SET

The `SET` clause specifies what should be changed.

Example:

```sql
SET age = 26
```

This means:

> Change the `age` column to `26`.

Multiple columns can be changed:

```sql
SET age = 28,
    country = 'France'
```

---

## 🎯 WHERE

The `WHERE` clause determines which rows should be updated.

Example:

```sql
UPDATE users
SET age = 26
WHERE id = 1;
```

The condition:

```sql
WHERE id = 1
```

makes the update target a specific user.

Without `WHERE`, an update can affect every row in the table.

## 🧪 Safe Update Workflow

Before updating a record, check it first:

```sql
SELECT *

```

Then perform the update:

```sql
UPDATE users

```

Finally, verify the change:

```sql

FROM users
WHERE id = 1;
```

This is a useful habit when working with real databases.

---

## 🧠 INSERT vs UPDATE

`INSERT` adds a new record:

```sql
INSERT INTO users (...)
VALUES (...);
```

`UPDATE` changes an existing record:

```sql
UPDATE users
SET age = 26
WHERE id = 1;
```

The difference is:

```text
INSERT → Add
UPDATE → Change
```

## ⚠️ Important Safety Lesson

Never casually run:

```sql
UPDATE users
SET age = 30;
```

without understanding the consequences.

Without a `WHERE` condition, the statement can update every row.

A safer targeted update is:

```sql
UPDATE users
SET age = 30
WHERE id = 3;
```

The `WHERE` clause is therefore one of the most important parts of an `UPDATE` statement.
