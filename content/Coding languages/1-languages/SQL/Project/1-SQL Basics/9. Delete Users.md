# 🔎 1. Delete One Specific User

Suppose you want to delete Alex Wilson, whose ID is `5`.

First, check the record:

```sql
SELECT *
FROM users
WHERE id = 5;
```

Make sure this is the correct user.

Then:

```sql
DELETE FROM users
WHERE id = 5;
```

Now verify:

```sql
SELECT *
FROM users
WHERE id = 5;
```

The query should return **no rows**.

---

# ⚠️ WHERE Is Extremely Important

This is the most important lesson in Project #9.

Consider:

```sql
DELETE FROM users
WHERE id = 5;
```

This means:

> Delete the user whose ID is 5.

But look at this:

```sql
DELETE FROM users;
```

There is **no `WHERE` condition**.

That means:

> Delete every row from the `users` table.

The table itself remains, but all its records can be removed.

So remember:

> **Never run a `DELETE` statement casually. Always check the `WHERE` condition first.**

---

# 🧠 DELETE vs UPDATE

You just learned `UPDATE`.

Compare them:

### UPDATE

```sql
UPDATE users
SET age = 30
WHERE id = 5;
```

Means:

> Find user 5 and change their age.

### DELETE

```sql
DELETE FROM users
WHERE id = 5;
```

Means:

> Find user 5 and remove the entire row.

So:

```text
INSERT → Add
SELECT → Read
UPDATE → Change
DELETE → Remove
```

These are the basic **CRUD operations**:

|Operation|SQL|Purpose|
|---|---|---|
|Create|`INSERT`|Add data|
|Read|`SELECT`|Retrieve data|
|Update|`UPDATE`|Modify data|
|Delete|`DELETE`|Remove data|

You've now practiced all four.

# 🔍 2. Delete Using Another Condition

You don't have to use `id`.

For example:

```sql
DELETE FROM users
WHERE country = 'Australia';
```

This removes users whose country is Australia.

However, be careful.

If multiple users match:

```text
User 1 → Australia
User 2 → Australia
User 3 → Canada
```

then the query deletes **both Australian users**.

That's why checking the condition with `SELECT` first is a good habit.

---

# 🧪 3. Check Before Delete

Use this workflow:

### Step 1 — Find the records

```sql
SELECT *
FROM users
WHERE id = 5;
```

### Step 2 — Confirm the result

Make sure you're deleting the correct user.

### Step 3 — Delete

```sql
DELETE FROM users
WHERE id = 5;
```

### Step 4 — Verify

```sql
SELECT *
FROM users
WHERE id = 5;
```

Expected:

```text
Empty result
```

This workflow is extremely valuable when working with real data.

---

# 🔢 4. Delete Multiple Rows

You can delete multiple records if they all match your condition.

For example:

```sql
DELETE FROM users
WHERE age < 25;
```

This means:

> Delete every user younger than 25.

If your data contains:

```text
Sara → 24
```

then Sara would be deleted.

If there were several users under 25, **all matching users would be deleted**.

So before running it, check:

```sql
SELECT *
FROM users
WHERE age < 25;
```

If the returned records are exactly the ones you intend to remove, then run the `DELETE`.

---

# 🧠 DELETE Doesn't Delete the Table

This is another important distinction.

When you write:

```sql
DELETE FROM users
WHERE id = 5;
```

you delete a **row**.

The table still exists:

```text
Database
  └── users table
       ├── User 1
       ├── User 2
       ├── User 3
       └── User 4
```

You're only removing records.

You're **not** removing the table itself.

---

# 🚫 DELETE vs DROP

You may eventually see:

```sql
DROP TABLE users;
```

This is very different.

### DELETE

```sql
DELETE FROM users
WHERE id = 5;
```

Removes rows.

### DROP TABLE

```sql
DROP TABLE users;
```

Removes the entire table structure and its data.

For this project:

> **Do not use `DROP TABLE`.**

It is outside the scope of Project #9.

---

# 🧠 DELETE vs TRUNCATE

You may also encounter:

```sql
TRUNCATE TABLE users;
```

For now, don't use it.

The distinction between `DELETE`, `TRUNCATE`, and `DROP` becomes more important as you learn database administration and transactions.

For this project, focus only on:

removes rows.

removes the table itself.

They are **not the same thing**.

## 🧠 Main SQL Concept

The main concept introduced in this project is:

```sql
DELETE
```

`DELETE` removes existing rows from a table.

Basic syntax:

```sql
DELETE FROM table
WHERE condition;
```

Example:

```sql
DELETE FROM users
WHERE id = 5;
```

This removes the user whose ID is `5`.

---

## 🎯 WHERE Clause

The `WHERE` clause determines which rows will be deleted.

Example:

```sql
DELETE FROM users
WHERE id = 5;
```

Only the matching record is targeted.

Without a `WHERE` condition:

```sql
DELETE FROM users;
```

all rows in the table can be deleted.

Therefore, the `WHERE` condition must always be considered carefully before executing a `DELETE`.

---

## 🧪 Safe Delete Workflow

Before deleting a record, first check it:

```sql
SELECT *
FROM users
WHERE id = 5;
```

After confirming the record, delete it:

```sql
DELETE FROM users
WHERE id = 5;
```

Then verify:

```sql
SELECT *
FROM users
WHERE id = 5;
```

The final query should return no matching record.
