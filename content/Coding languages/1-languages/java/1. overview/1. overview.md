## 🎯  زبان  Java چیست؟
جاوا (**Java**) یک زبان برنامه‌نویسی **همه‌منظوره**، **شی‌گرا** و **همزمان** است که توسط شرکت **Sun Microsystems** (اکنون متعلق به **Oracle**) ساخته شده است. این زبان بر اساس فلسفهٔ (یک‌بار بنویس، هرجا اجرا کن) طراحی شده است. 

کدهای جاوا به **بایت‌کد (Bytecode)** تبدیل می‌شوند و روی **ماشین مجازی جاوا (JVM)** اجرا می‌شوند؛ به همین دلیل، روی هر سیستمی که JVM داشته باشد (ویندوز، لینوکس، مک، اندروید و حتی برخی کارت‌های هوشمند) قابل اجراست.

جاوا یکی از محبوب‌ترین زبان‌های برنامه‌نویسی جهان است و در حوزه‌های مختلفی مانند توسعه‌ی برنامه‌های موبایل (اندروید)، اپلیکیشن‌های سازمانی (Enterprise)، سیستم‌های مالی، وب، علوم داده و حتی بازی‌سازی کاربرد دارد.

## 🛠️ ویژگی‌های کلیدی جاوا

| ویژگی | توضیح |
|--------|---------|
| **استقلال از پلتفرم** | کد جاوا روی هر سیستمی که JVM داشته باشد، اجرا می‌شود. |
| **شی‌گرایی (OOP)** | همه‌چیز در جاوا بر پایهٔ اشیاء و کلاس‌ها طراحی شده است. |
| **مدیریت خودکار حافظه** | زباله‌روب (Garbage Collector) به‌طور خودکار حافظهٔ غیرضروری را پاک‌سازی می‌کند. |

| **هم‌روندی (Concurrency)** | پشتیبانی از چندنخی (Multi-threading) و پردازش همزمان. |
| **منبع‌باز بودن** | از سال ۲۰۰۶، کد منبع جاوا در دسترس عموم است. |

## 🧩 معماری جاوا (Java Architecture)
معماری جاوا از سه بخش اصلی تشکیل شده است:

1. **زبان برنامه‌نویسی جاوا** (Syntax, Keywords, OOP, etc.)
2. **JDK (Java Development Kit)** : شامل کامپایلر (`javac`)، ابزارهای توسعه و JRE.
3. **JRE (Java Runtime Environment)** : شامل JVM و کتابخانه‌های اجرایی.
4. **JVM (Java Virtual Machine)** : قلب جاوا که بایت‌کد را تفسیر یا کامپایل می‌کند.

## 📦 نسخه‌های مهم جاوا (LTS)

| نسخه | سال انتشار | ویژگی‌های مهم |
|------|------------|---------------|
| Java 8 | ۲۰۱۴ | Lambda، Stream API، Optional |
| Java 11 | ۲۰۱۸ | HttpClient، Local-Variable Syntax |
| Java 17 | ۲۰۲۱ | Sealed Classes، Pattern Matching |
| Java 21 | ۲۰۲۳ | Virtual Threads، Scoped Values |

> نکته: **LTS** یعنی پشتیبانی طولانی‌مدت؛ این نسخه‌ها برای پروژه‌های سازمانی توصیه می‌شوند.

## 🚀 شروع سریع
برای شروع کار با جاوا، مراحل زیر را دنبال کنید:

1. **نصب JDK** (Oracle JDK یا OpenJDK)
2. **نصب یک IDE** (IntelliJ IDEA، Eclipse یا VS Code)
3. **نوشتن اولین برنامه**:
```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```
4. **کامپایل و اجرا**:
```bash
javac HelloWorld.java
java HelloWorld
```
