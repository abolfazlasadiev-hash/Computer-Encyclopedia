## 🌍 اکوسیستم جاوا چیست؟

اکوسیستم جاوا مجموعه‌ای از **ابزارها، کتابخانه‌ها، فریمورک‌ها، سرورها، پایگاه‌های داده، و جامعه‌ی توسعه‌دهندگان** است که در کنار یکدیگر، یک محیط کامل برای توسعه‌ی نرم‌افزار با جاوا فراهم می‌کنند. این اکوسیستم یکی از بزرگترین و غنی‌ترین اکوسیستم‌های برنامه‌نویسی در جهان است.

## 📦 ۱. JDK و JRE (ماشین مجازی و کتابخانه‌های پایه)

### JDK (Java Development Kit)
- شامل کامپایلر (`javac`)، JRE و ابزارهای توسعه
- نسخه‌های معروف: Oracle JDK، OpenJDK، Amazon Corretto، Azul Zulu

### JRE (Java Runtime Environment)
- شامل JVM و کتابخانه‌های اصلی
- برای اجرای برنامه‌های جاوا

### JVM (Java Virtual Machine)
- قلب اکوسیستم جاوا
- انواع مختلف: HotSpot (Oracle)، OpenJ9 (IBM)، GraalVM

```bash
# بررسی نسخه‌ی JDK
java -version
# javac -version
```

### ارائه‌دهندگان اصلی JDK

| ارائه‌دهنده | توضیح |
|-------------|-------|
| **Oracle JDK** | نسخه‌ی رسمی و تجاری (LTS با پشتیبانی پولی) |
| **OpenJDK** | نسخه‌ی متن‌باز و رایگان (مرجع اصلی) |
| **Amazon Corretto** | نسخه‌ی رایگان و پشتیبانی‌شده توسط AWS |
| **Azul Zulu** | نسخه‌ی بهینه‌شده برای عملکرد بالا |
| **Adoptium (Eclipse Temurin)** | نسخه‌ی جامعه‌محور و رایگان |

## 🛠️ ۲. ابزارهای Build (ساخت و مدیریت پروژه)

### Maven
- استانداردترین ابزار build در جاوا
- مدیریت وابستگی‌ها (Dependencies)
- ساختار پروژه یکپارچه

```xml
<!-- pom.xml -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
    <version>3.2.0</version>
</dependency>
```

### Gradle
- انعطاف‌پذیرتر از Maven
- استفاده از Groovy یا Kotlin DSL
- سریع‌تر برای پروژه‌های بزرگ

```gradle
// build.gradle
dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-web:3.2.0'
}
```

### ابزارهای دیگر
- **Ant**: قدیمی‌ترین ابزار build
- **Bazel**: از گوگل، مناسب برای پروژه‌های بزرگ
- **Jib**: ساخت Docker image برای برنامه‌های جاوا (از گوگل)

## 🧪 ۸. ابزارهای تست

### تست‌نویسی
- **JUnit 5**: استاندارد اصلی تست
- **TestNG**: جایگزین JUnit با قابلیت‌های بیشتر
- **Spock**: تست با Groovy (خوانایی بالا)

### Mocking
- **Mockito**: محبوب‌ترین
- **EasyMock**: قدیمی‌تر
- **PowerMock**: برای تست کدهای قدیمی

### Integration Testing
- **Testcontainers**: تست با داکر
- **WireMock**: شبیه‌سازی APIها

```java
@SpringBootTest
public class UserServiceTest {
    
    @Mock
    private UserRepository userRepository;
    
    @InjectMocks
    private UserService userService;
    
    @Test
    void shouldFindUserById() {
        when(userRepository.findById(1L))
            .thenReturn(Optional.of(new User(1L, "John", "john@email.com")));
        
        User user = userService.findById(1L);
        assertEquals("John", user.getName());
    }
}
```

## ✨ جمع‌بندی

اکوسیستم جاوا یکی از **غنی‌ترین، بالغ‌ترین و بزرگ‌ترین** اکوسیستم‌های برنامه‌نویسی در جهان است. از ابزارهای build تا فریمورک‌های مدرن، از پایگاه‌های داده تا سرویس‌های ابری، همه‌چیز در این اکوسیستم وجود دارد. این تنوع و غنا، جاوا را به انتخابی عالی برای **پروژه‌های بزرگ و بلندمدت** تبدیل کرده است.

> 💡 **نکته**: یادگیری کامل اکوسیستم جاوا زمان‌بر است، اما تسلط بر ابزارهای اصلی (Spring Boot, Maven/Gradle, JUnit, IntelliJ IDEA) شما را به یک توسعه‌دهنده‌ی حرفه‌ای تبدیل می‌کند.
