
## 📜 تاریخچه نسخه‌های جاوا

جاوا از زمان انتشار اولیه در سال ۱۹۹۵ تاکنون، نسخه‌های متعددی را پشت سر گذاشته است. در این بخش، نسخه‌های مهم جاوا، ویژگی‌های کلیدی هر نسخه و تغییرات مهم را بررسی می‌کنیم.

## 🆕 بررسی نسخه‌های مهم و تغییرات کلیدی

### ☕ Java 1.0 (1995) - تولد جاوا
- **اولین انتشار رسمی** جاوا
- شعار معروف: **"Write Once, Run Anywhere"**
- کتابخانه‌های پایه و AWT (Abstract Window Toolkit)

---

### ☕ Java 1.1 (1997) - اولین به‌روزرسانی بزرگ
- **JDBC** (اتصال به پایگاه داده)
- **Reflection API** (بررسی کد در زمان اجرا)
- **Inner Classes** (کلاس‌های درونی)
- **JavaBeans** (کامپوننت‌های قابل استفاده مجدد)

---

### ☕ J2SE 1.2 (1998) - Java 2
- **Collections Framework** (List, Set, Map)
- **Swing** (رابط کاربری گرافیکی پیشرفته)
- **JIT Compiler** (بهبود عملکرد)
- **Java Plug-in** برای مرورگرها

---

### ☕ J2SE 1.3 (2000) - بهبود عملکرد
- **HotSpot JVM** (بهینه‌سازی پویا)
- **JNDI** (Java Naming and Directory Interface)
- بهبود عملکرد و پایداری

---

### ☕ J2SE 1.4 (2002) - ویژگی‌های جدید
- **Regular Expressions** (عبارات با قاعده)
- **NIO** (New I/O - ورودی/خروجی غیرمسدودکننده)
- **Logging API** (لاگ‌نویسی)
- **Assertions** (تأییدیه‌ها)
- **XML Parser**

---

### ☕ Java 5 (2004) - انقلاب در جاوا
- **Generics** (نوع‌های پارامتری)
- **Enum** (شمارش‌گرها)
- **Varargs** (پارامترهای متغیر)
- **Enhanced for-loop** (حلقه‌ی for-each)
- **Annotation** (نوشتارهای فراداده)
- **Static Import**
- **Concurrency Utilities** (java.util.concurrent)

```java
// Java 5 - Generics
List<String> list = new ArrayList<String>();

// Enum
enum Day { MONDAY, TUESDAY, WEDNESDAY }

// Varargs
public void print(String... messages) { ... }

// Enhanced for-loop
for (String s : list) { ... }

// Annotation
@Override
public String toString() { ... }
```

### ☕ Java 6 (2006) - بهبود و پایداری
- بهبود **عملکرد** و **پایداری**
- پشتیبانی از **Scripting** (با JavaScript)
- بهبود **JMX** (مدیریت و مانیتورینگ)
- **JDBC 4.0**
- اولین نسخه‌ی متن‌باز (OpenJDK)

---

### ☕ Java 7 (2011) - بهبودهای عملی
- **Try-with-resources** (مدیریت خودکار منابع)
- **NIO.2** (سیستم فایل جدید)
- **Fork/Join Framework** (پردازش موازی)
- **Diamond Operator** (`<>` برای Generics)
- **Strings in Switch** (استفاده از String در Switch)
- **Underscores in Numeric Literals** (جداساز در اعداد)

```java
// Java 7 - Try-with-resources
try (BufferedReader br = new BufferedReader(new FileReader("file.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} // برخودکار بسته می‌شود

// Diamond Operator
List<String> list = new ArrayList<>();

// Strings in Switch
switch (day) {
    case "MONDAY": System.out.println(1); break;
    case "TUESDAY": System.out.println(2); break;
}
```

### ☕ Java 8 (2014) - تحول بزرگ **LTS**
- **Lambda Expressions** (توابع بی‌نام)
- **Stream API** (پردازش داده به‌صورت تابعی)
- **Optional** (جلوگیری از NullPointerException)
- **Date/Time API** (java.time)
- **Default Methods** در Interfaceها
- **Method References** (ارجاع به متدها)
- **CompletableFuture** (برنامه‌نویسی ناهم‌زمان)
- **Nashorn JavaScript Engine**

```java
// Java 8 - Lambda
List<String> names = Arrays.asList("Ali", "Sara", "Hassan");
names.forEach(name -> System.out.println(name));

// Stream API
List<String> filtered = names.stream()
    .filter(name -> name.startsWith("A"))
    .collect(Collectors.toList());

// Optional
Optional<String> optional = Optional.ofNullable(getName());
optional.ifPresent(name -> System.out.println("Hello " + name));

// Date/Time API
LocalDate today = LocalDate.now();
LocalDate birthday = LocalDate.of(1990, Month.JANUARY, 1);
```

> **نکته**: Java 8 هنوز هم پرکاربردترین نسخه‌ی جاوا در صنعت است!

### ☕ Java 11 (2018) - LTS دوم
- **HttpClient** (HTTP/2 Client - نهایی شده)
- **Local-Variable Syntax for Lambda**
- **Launch Single-File Source-Code Programs** (بدون کامپایل)
- **Nest-Based Access Control**
- **TLS 1.3**
- **ZGC** (Z Garbage Collector - Preview)
- **Epsilon GC** (No-op)

```java
// Java 11 - HttpClient
HttpClient client = HttpClient.newHttpClient();
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.example.com/data"))
    .build();

HttpResponse<String> response = client.send(
    request, HttpResponse.BodyHandlers.ofString()
);
System.out.println(response.body());

// Lambda with var
list.forEach((var s) -> System.out.println(s));
```

### ☕ Java 17 (2021) - LTS سوم ⭐
- **Sealed Classes** (Final)
- **Pattern Matching for Switch** (Preview)
- **Enhanced Pseudo-Random Number Generators**
- **Foreign Function & Memory API** (Incubator)
- **Context-Specific Deserialization Filters**

```java
// Java 17 - Sealed Classes
public sealed class Shape 
    permits Circle, Rectangle, Triangle { }

final class Circle extends Shape { }
final class Rectangle extends Shape { }
final class Triangle extends Shape { }

// Pattern Matching for Switch
String result = switch (shape) {
    case Circle c -> "Circle with radius " + c.radius();
    case Rectangle r -> "Rectangle with area " + r.area();
    case Triangle t -> "Triangle with area " + t.area();
};
```

## ⚠️ نکات مهم درباره‌ی نسخه‌ها

1. **LTS مهم است**: نسخه‌های LTS پشتیبانی بلندمدت دارند (تا ۸ سال)
2. **به‌روزرسانی منظم**: هر ۶ ماه یک نسخه‌ی جدید منتشر می‌شود
3. **مهاجرت تدریجی**: از Java 8 به نسخه‌های جدید نیاز به تغییرات دارد
4. **ابزارها**: مطمئن شوید IDE و ابزارهای شما از نسخه پشتیبانی می‌کنند

## ✨ جمع‌بندی

جاوا در طول بیش از ۲۵ سال، مسیر تکامل طولانی‌ای را طی کرده است. از نسخه‌های ابتدایی با قابلیت‌های محدود تا Java 21 با ویژگی‌های مدرن مانند Virtual Threads. **نسخه‌های LTS** (۸، ۱۱، ۱۷، ۲۱) مهم‌ترین نسخه‌ها هستند و برای پروژه‌های جدی توصیه می‌شوند. با هر نسخه، جاوا قدرتمندتر و به‌روزتر می‌شود و همچنان در صنعت نرم‌افزار حضوری پررنگ دارد.

> 💡 **نکته**: اگر تازه شروع کرده‌اید، با Java 17 یا 21 شروع کنید تا با جدیدترین ویژگی‌ها آشنا شوید.
