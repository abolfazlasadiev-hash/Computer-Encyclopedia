# 🧠 Definition of Done برای تمام 100 پروژه

یک پروژه را فقط وقتی تمام‌شده حساب کن که این موارد را داشته باشد:

### Level 1 — Functional

-  برنامه compile می‌شود.
    
-  برنامه اجرا می‌شود.
    
-  مثال اصلی مسئله درست جواب می‌دهد.
    
-  خروجی قابل فهم است.
    

### Level 2 — Edge Cases

-  ورودی خالی بررسی شده.
    
-  صفر بررسی شده.
    
-  مقادیر منفی بررسی شده، اگر مرتبط است.
    
-  ورودی نامعتبر بررسی شده.
    
-  overflow / division by zero در موارد مرتبط بررسی شده.
    

### Level 3 — Code Quality

-  نام متغیرها واضح است.
    
-  متدهای خیلی بزرگ نداری.
    
-  منطق اصلی قابل فهم است.
    
-  کد تکراری غیرضروری نداری.
    
-  `Main` تبدیل به یک فایل 300 خطی نشده.
    

### Level 4 — Understanding

قبل از رفتن به پروژه بعدی بتوانی **بدون نگاه کردن به کدت** توضیح بدهی:

> «ورودی چیست؟  
> چه اتفاقی روی ورودی می‌افتد؟  
> خروجی چیست؟  
> چه Edge Caseهایی وجود دارد؟  
> چرا این ساختار Java را انتخاب کردم؟»
