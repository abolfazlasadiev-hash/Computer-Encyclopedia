
### `Main.java`

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

## 1. `public class Main`

```java
public class Main {
```

This creates a **class** called `Main`.

- `class` tells Java that we are creating a class.
    
- `Main` is the name of the class.
    
- `public` means the class can be accessed from anywhere.
    

Think of a **class as a container** that holds our Java code.

The opening `{` means the body of the class starts here.

---

## 2. `public static void main(String[] args)`

```java
public static void main(String[] args) {
```

This is the **main method**.

The main method is extremely important because it is where a Java application normally **starts running**.

### `public`

```java
public
```

Means the method is accessible from outside the class.

Java needs to be able to access the `main` method when starting the program.

### `static`

```java
static
```

Means Java can run this method **without creating an object of the `Main` class**.

For now, you can simply remember:

> `static` allows the `main` method to run directly.

You'll learn the deeper meaning of `static` later when you study OOP.

### `void`

```java
void
```

Means the method **doesn't return a value**.

For example, a method returning a number could use:

```java
int
```

But our `main` method doesn't return anything, so we use:

```java
void
```

### `main`

```java
main
```

`main` is the special name Java looks for when starting a normal Java program.

### `String[] args`

```java
String[] args
```

This is an array of `String` values used for **command-line arguments**.

For this first program, you don't need to use it. Just remember that the standard Java main method is:

```java
public static void main(String[] args)
```

---

## 3. `System.out.println()`

```java
System.out.println("Hello, World!");
```

This tells Java to **print text to the console**.

Let's break it down.

### `System`

```java
System
```

`System` is a built-in Java class that provides access to various system features.

### `out`

```java
System.out
```

`out` represents the standard output stream — normally your console/terminal.

### `println`

```java
System.out.println()
```

`println` means **print line**.

It prints the specified text and then moves to a new line.

### `"Hello, World!"`

```java
"Hello, World!"
```

This is a **String**, meaning a piece of text.

The quotation marks tell Java:

> This is text; don't treat it as Java code.

---

## 4. The semicolon `;`

```java
System.out.println("Hello, World!");
                                      ^
```

The `;` marks the end of a Java statement.

For example:

```java
System.out.println("Hello");
System.out.println("World");
```

Each statement ends with `;`.

---

## 5. The curly braces `{ }`

Our program has several `{ }` pairs:

```java
public class Main {
    
    public static void main(String[] args) {
        
        System.out.println("Hello, World!");
        
    }
}
```

The first pair belongs to the class:

```java
public class Main {
    ...
}
```

The second pair belongs to the `main` method:

```java
public static void main(String[] args) {
    ...
}
```

So the structure is:

```text
Main class
│
└── main method
    │
    └── print "Hello, World!"
```

---

## 6. How Java runs this program

When you run the program, Java essentially follows this path:

```text
Start program
     ↓
Find Main class
     ↓
Find main() method
     ↓
Execute System.out.println()
     ↓
Print "Hello, World!"
     ↓
Program finishes
```

The result is:

```text
Hello, World!
```
