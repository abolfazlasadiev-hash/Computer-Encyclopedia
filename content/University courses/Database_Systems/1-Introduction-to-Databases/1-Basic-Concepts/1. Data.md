## Definition

**Data** is a collection of raw facts, figures, symbols, or observations that have not yet been processed or organized to provide meaningful understanding.

In simple terms:

> **Data = Raw facts and figures**

Data can be numbers, text, dates, images, audio, video, or other forms of recorded information.

---

## Examples

Examples of data include:

- `101`
- `Ali`
- `85`
- `2026-09-06`
- `Computer Science`
- `5000`
- `A`
- `John, 20, 85`

Individually, these values may not provide much meaning.

For example:

```text
Ali
20
85
````

These are raw data values. We do not immediately know whether `20` represents age, marks, or something else.

After organizing and processing the data:

```text
Student: Ali
Age: 20
Marks: 85
```

the values become meaningful information.

---

## Types of Data

Data can exist in several forms.

### 1. Numeric Data

Data represented using numbers.

Examples:

```text
100
25.5
75
2026
```

It can represent values such as age, salary, marks, quantity, or price.

### 2. Character or Text Data

Data represented using letters, words, or sentences.

Examples:

```text
Ali
Database Systems
Computer Science
```

### 3. Date and Time Data

Data representing dates or times.

Examples:

```text
2026-09-06
14:30:00
```

### 4. Multimedia Data

Data containing images, audio, or video.

Examples:

- Student photograph
    
- Recorded lecture
    
- Training video
    
- Product image
    

### 5. Boolean Data

Data with two possible logical values.

```text
TRUE
FALSE
```

For example:

```text
is_active = TRUE
```

---

## Data in a Database

A database stores data in an organized manner so that it can be easily accessed, managed, updated, and retrieved.

For example, a `Student` table may contain:

|Student_ID|Name|Age|Marks|
|---|---|--:|--:|
|101|Ali|20|85|
|102|Sara|21|91|
|103|John|19|78|

Here, each value stored in the table is **data**.

A DBMS can process this data to produce useful information.

For example:

```sql
SELECT Name
FROM Student
WHERE Marks > 80;
```

Result:

```text
Ali
Sara
```

---

## Data vs Information

Data and information are related but different.

|Data|Information|
|---|---|
|Raw facts|Processed and meaningful data|
|May have little meaning by itself|Provides meaning and context|
|Input for processing|Output of processing|
|Example: `85`|Example: `Ali scored 85 marks`|

Therefore:

> **Data is the raw material, while information is the meaningful result obtained after processing data.**

---

## Importance of Data in Database Systems

Data is the most important resource managed by a database system.

A DBMS allows organizations to:

- Store data
    
- Retrieve data
    
- Update data
    
- Delete data
    
- Organize data
    
- Share data
    
- Protect data
    
- Analyze data
    
- Maintain data consistency
    

Examples of organizations that depend heavily on data include:

- Banks
    
- Hospitals
    
- Universities
    
- Libraries
    
- E-commerce companies
    
- Government organizations

## Key Points

1. **Data consists of raw facts and figures.**
    
2. Data can be numeric, textual, multimedia, date/time, or Boolean.
    
3. Data becomes information after it is processed and given meaning.
    
4. Databases store and organize large amounts of data.
    
5. A DBMS provides facilities for storing, retrieving, updating, and managing data.
    
6. Data is the basic resource on which database systems operate.
