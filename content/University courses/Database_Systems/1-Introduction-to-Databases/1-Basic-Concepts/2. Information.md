## Definition

**Information** is processed, organized, and meaningful data that helps people understand something or make decisions.

In simple terms:

> **Information = Processed and meaningful data**

Data becomes information when it is processed, organized, interpreted, and given context.

---

## Example

Suppose we have the following raw data:

```text
Ali
20
85
```

This data by itself does not clearly explain what each value represents.

After processing and organizing it:

```text
Student Name: Ali
Age: 20
Marks: 85
```

This is **information** because the data now has meaning and context.

---

## Another Example

Consider the following data:

```text
70, 80, 90, 60, 100
```

These are raw values.

After processing them, we can calculate the average:

```text
Average = 80
```

The statement:

> "The average mark is 80."

is information because it provides a meaningful result from the original data.

---

## Characteristics of Information

Good information generally has the following characteristics:

### 1. Accuracy

Information should be correct and free from errors.

Example:

```text
Student marks = 85
```

If the actual marks are 85, the information is accurate.

### 2. Relevance

Information should be related to the purpose for which it is being used.

For example, a student's attendance percentage is relevant when deciding whether the student meets an attendance requirement.

### 3. Timeliness

Information should be available when it is needed.

For example, current stock information is important when processing a customer's order.

### 4. Completeness

Information should contain all necessary details.

For example, a student report should contain the required student details, subjects, and marks.

### 5. Understandability

Information should be presented in a form that users can easily understand.

---

## Data vs Information

|Data|Information|
|---|---|
|Raw facts and figures|Processed data|
|May not have clear meaning|Has meaningful context|
|Used as input for processing|Produced as a result of processing|
|Usually unorganized|Usually organized|
|Example: `85`|Example: `Ali scored 85 marks`|

### Relationship

The basic relationship can be represented as:

```text
Data
  ↓
Processing
  ↓
Information
```

---

## Information in Database Systems

A database stores data, while a DBMS allows users and applications to process that data to obtain useful information.

For example, a university database may contain:

|Student_ID|Name|Department|Marks|
|---|---|---|--:|
|101|Ali|CS|85|
|102|Sara|IT|91|
|103|John|CS|78|

The stored values are **data**.

A query such as:

```sql
SELECT Name, Marks
FROM Student
WHERE Marks >= 80;
```

can produce:

|Name|Marks|
|---|--:|
|Ali|85|
|Sara|91|

This result is useful **information** for identifying students who scored at least 80 marks.

## Importance of Information

Information helps organizations:

- Make decisions
    
- Monitor performance
    
- Identify problems
    
- Plan activities
    
- Analyze trends
    
- Improve services
    
- Support business operations
    

For example, a bank can process transaction data to produce information about account balances and transaction history.

---

## Data → Information → Knowledge

Data and information can be viewed as stages of processing:

```text
Raw Data
   ↓
Processing
   ↓
Information
   ↓
Analysis / Interpretation
   ↓
Knowledge
```

For example:

```text
Data:
80, 85, 90, 95

        ↓

Information:
Average mark = 87.5

        ↓

Knowledge:
Student performance is generally high.
```

---

## Key Points

1. **Information is processed and meaningful data.**
    
2. Data becomes information after processing and organization.
    
3. Good information should be accurate, relevant, timely, complete, and understandable.
    
4. A DBMS processes stored data to provide useful information.
    
5. Information supports decision-making and business operations.
