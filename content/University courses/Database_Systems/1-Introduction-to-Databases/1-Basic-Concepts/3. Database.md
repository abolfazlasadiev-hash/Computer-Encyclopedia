## Definition

A **database** is an organized collection of related data that is stored and managed so that it can be easily accessed, retrieved, updated, and maintained.

In simple terms:

> **Database = An organized collection of related data**

A database allows large amounts of data to be stored systematically instead of keeping information in separate, unorganized files.

---

## Example

Consider a university database containing student information:

|Student_ID|Name|Age|Department|
|---|---|--:|---|
|101|Ali|20|Computer Science|
|102|Sara|21|Information Technology|
|103|John|19|Computer Science|

The table contains related data about students.

Together, these records can form part of a **University Database**.

## Components of a Database

A database commonly contains the following elements:

### 1. Data

The actual facts stored in the database.

Example:

```text
Student_ID = 101
Name = Ali
Age = 20
```

### 2. Tables

In a relational database, data is organized into tables.

Example:

```text
Student
-------------------------
Student_ID | Name | Age
101        | Ali  | 20
102        | Sara | 21
```

### 3. Records

A **record** represents a complete set of related data about one entity.

Example:

```text
101 | Ali | 20 | Computer Science
```

This represents one student's record.

### 4. Fields

A **field** represents a particular attribute or piece of information.

For example:

```text
Student_ID
Name
Age
Department
```

are fields of a Student table.

## Database Operations

Data in a database can be managed using several basic operations:

### Create

Add new data or database objects.

### Read

Retrieve or view stored data.

### Update

Modify existing data.

### Delete

Remove unwanted data.

These operations are commonly referred to as **CRUD**:

```text
C → Create
R → Read
U → Update
D → Delete
```

## Database and DBMS

A **database** and a **DBMS** are not the same thing.

|Database|DBMS|
|---|---|
|Collection of organized data|Software used to manage databases|
|Stores the data|Provides facilities to store, retrieve, update, and control data|
|Example: Student records|Example: MySQL, PostgreSQL, Oracle Database|

A DBMS provides an interface between users/applications and the database.

```text
User / Application
        ↓
       DBMS
        ↓
    Database
```

- Data security

- Data consistency
    
- Reduced data redundancy

---

## Advantages of Using Databases

### 1. Easy Data Access

Users can quickly search and retrieve required data.

### 2. Reduced Redundancy

A well-designed database reduces unnecessary duplication of data.

### 3. Improved Data Consistency

When duplicate data is minimized and updates are properly managed, data is more likely to remain consistent.

### 4. Data Security

Access controls can restrict unauthorized users from accessing sensitive data.

### 5. Data Sharing

Multiple authorized users and applications can access the same database.

### 6. Backup and Recovery

Database systems can provide mechanisms for backing up data and recovering it after failures.

## Database vs File System

Traditional file systems store information in separate files, while a database system provides a structured and controlled way to manage related data.

For example:

```text
File System
├── students.txt
├── courses.txt
├── teachers.txt
└── results.txt
```

A database system can organize related information into tables and establish relationships between them.

The limitations of traditional file systems and the advantages of DBMS are discussed in later topics.
