## Definition

A **database system** is a complete system used to store, manage, retrieve, and process data in a database.

It consists of the **database**, the **DBMS**, application programs, users, and supporting hardware and software.

In simple terms:

> **Database System = Database + DBMS + Users + Applications + Supporting Resources**

---

## Components of a Database System

A database system generally consists of the following major components:

### 1. Database

The **database** is the organized collection of data that needs to be stored and managed.

For example:

```text
Student
--------------------------------
Student_ID | Name | Age | Marks
101        | Ali  | 20  | 85
102        | Sara | 21  | 91
```

---

### 2. DBMS

A **Database Management System (DBMS)** is software that manages the database.

It allows users and applications to:

- Store data
    
- Retrieve data
    
- Insert new data
    
- Update existing data
    
- Delete data
    
- Control access
    
- Maintain data integrity
    
- Perform backup and recovery
    

Examples of DBMS software include:

- MySQL
    
- PostgreSQL
    
- Oracle Database
    
- Microsoft SQL Server
    
- SQLite
    

---

### 3. Users

Users are people who interact with the database system.

Different users have different responsibilities and levels of access.

Examples include:

- Database administrators
    
- Application programmers
    
- Database designers
    
- End users
    
- System analysts
    

---

### 4. Application Programs

Application programs provide user-friendly interfaces for interacting with the database.

For example, a banking application may allow a customer to:

```text
Login
  ↓
View Account Balance
  ↓
Transfer Money
  ↓
View Transactions
```

The application communicates with the DBMS to perform these operations.

---

### 5. Hardware

Hardware includes the physical devices used to run and store the database system.

Examples:

- Servers
    
- Storage devices
    
- Computers
    
- Network equipment
    
- Backup devices
    

---

### 6. Software

Besides the DBMS, a database system may depend on other software such as:

- Operating systems
    
- Network software
    
- Application software
    
- Backup software
    
- Monitoring tools
    

---

### 7. Procedures

**Procedures** are rules and instructions that describe how the database system should be used and managed.

Examples:

- Backup procedures
    
- Security procedures
    
- Data recovery procedures
    
- User access procedures
    
- Maintenance procedures
    

---

## Database System Architecture

A simplified database system can be represented as:

```text
             Users
               ↓
       Application Programs
               ↓
              DBMS
               ↓
            Database
               ↓
       Storage / Hardware
```

The DBMS acts as an intermediary between users or applications and the stored data.

## Database vs DBMS vs Database System

These terms should not be confused.

|Term|Meaning|
|---|---|
|**Database**|Organized collection of data|
|**DBMS**|Software used to manage the database|
|**Database System**|Complete environment consisting of database, DBMS, users, applications, and supporting resources|

### Example

```text
Database:
Student records

DBMS:
MySQL

Database System:
Student records + MySQL + applications + users + hardware + procedures
```

## Functions of a Database System

A database system provides many important functions:

### 1. Data Storage

Stores large amounts of data in an organized manner.

### 2. Data Retrieval

Allows users to retrieve required data efficiently.

### 3. Data Modification

Allows data to be inserted, updated, and deleted.

### 4. Data Security

Controls who can access particular data.

### 5. Data Integrity

Ensures that stored data remains accurate and valid.

### 6. Concurrency Control

Allows multiple users to access the database while preventing conflicting operations.

### 7. Backup and Recovery

Helps protect data against system failures and restore data when necessary.

### 8. Transaction Management

Ensures that database transactions are executed reliably.

## Real-World Example

Consider an online shopping system.

```text
Customer
   ↓
Shopping Application
   ↓
      DBMS
   ↓
Database
```

The database may contain:

```text
CUSTOMER
PRODUCT
ORDER
PAYMENT
DELIVERY
```

When a customer places an order:

1. The application receives the order.
    
2. The application sends a request to the DBMS.
    
3. The DBMS processes the request.
    
4. The database is updated.
    
5. The application displays the result to the customer.
    

Thus, the database system coordinates the complete process.

---

## Key Points

1. A **database system** is a complete environment for managing data.
    
2. It includes the database, DBMS, users, applications, hardware, software, and procedures.
    
3. The DBMS acts as an interface between users/applications and the database.
    
4. Database systems provide storage, retrieval, security, integrity, concurrency, and recovery.
    
5. Database, DBMS, and database system are different concepts.
