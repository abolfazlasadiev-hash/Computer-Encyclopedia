**Data communication** means the **exchange of data between two or more devices through some transmission medium**.

For example:

> You send a WhatsApp message → your phone sends the data → the network carries it → your friend's phone receives it.

So, simply:

**Sender → Transmission Medium → Receiver**

### Main components

A data communication system generally involves:

1. **Sender (Source)**  
    The device that sends the data.  
    _Example: Your phone_
    
2. **Receiver (Destination)**  
    The device that receives the data.  
    _Example: Your friend's phone_
    
3. **Message (Data)**  
    The information being transmitted.  
    _Example: Text, image, audio, video, file_
    
4. **Transmission Medium**  
    The path through which data travels.  
    _Example: Ethernet cable, fiber optic cable, Wi-Fi/radio waves_
    
5. **Protocol**  
    The rules that control communication between devices.  
    _Example: TCP/IP_

### Example: Sending an email

Suppose **A wants to send an email to B**:

```text
A's Computer
     ↓
   Email
     ↓
Network / Internet
     ↓
Mail Server
     ↓
Internet
     ↓
B's Computer
```

The email is the **message**, A's computer is the **sender**, B's computer is the **receiver**, the Internet is the **transmission medium/network**, and protocols such as **SMTP** help control the communication.

### Important characteristics

Good data communication should have:

- **Delivery** → Data reaches the correct destination.
    
- **Accuracy** → Data should arrive without errors.
    
- **Timeliness** → Data should arrive when needed.
    
- **Low jitter** → Variation in packet arrival time should be small, especially for audio/video.
    

### Data Communication vs Computer Network

These two terms are related but not identical:

**Data Communication:**  
Focuses on **transferring data** between devices.

**Computer Network:**  
A collection of interconnected devices that allows **communication and resource sharing**.

For exam purposes, remember:

> **Data Communication = Exchange of data between devices.**

And the basic communication model is:

**Sender → Message → Medium → Receiver**, controlled by **protocols**.
