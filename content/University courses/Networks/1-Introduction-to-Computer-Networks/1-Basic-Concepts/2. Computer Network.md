
Let's continue from **01. Data Communication** and explain **Computer Network** clearly and in an exam-friendly way.

### 1. What is a Computer Network?

A **computer network** is a collection of two or more computers/devices connected together so that they can **communicate and share data and resources**.

**Simple definition:**

> A computer network is a group of interconnected devices that communicate with each other using communication protocols.

### 2. Why do we need a network?

Networks allow devices to share:

- 📁 **Files and data**
    
- 🖨️ **Printers and other hardware**
    
- 🌐 **Internet connection**
    
- 💾 **Storage**
    
- 📱 **Applications and services**
    
- 💬 **Messages and information**
    

### 3. Simple example

Imagine a college computer lab:

```text
       Computer 1
           │
Computer 2 ─┼─ Switch ── Printer
           │
       Computer 3
           │
         Router
           │
        Internet
```

All computers can communicate through the network. They can also share the printer and access the Internet.

## 4. Basic elements of a Computer Network

A network generally contains:

### A. Nodes / Devices

These are devices connected to the network.

Examples:

- Computer
    
- Laptop
    
- Smartphone
    
- Printer
    
- Server
    
- Router
    
- Switch
    

### B. Communication Links

These are the paths through which data travels.

Two major types:

**Wired**

- Twisted-pair cable
    
- Coaxial cable
    
- Fiber-optic cable
    

**Wireless**

- Wi-Fi
    
- Radio
    
- Microwave
    
- Satellite
    

### C. Protocols

A **protocol** is a set of rules that devices follow when communicating.

For example:

- TCP/IP
    
- HTTP
    
- FTP
    
- SMTP
    

Think of a protocol like **traffic rules**. Without common rules, devices would not know how to communicate properly.

# 5. Network Criteria

Your syllabus identifies three important criteria for evaluating a network: **performance, reliability, and security**.

### ① Performance

Performance tells us **how well and how quickly the network works**.

Important terms include:

- Bandwidth
    
- Throughput
    
- Delay/Latency
    
- Response time
    

**Example:**  
A network that transfers a 1 GB file in 10 seconds performs better than one that takes 5 minutes, assuming other conditions are comparable.

### ② Reliability

Reliability means **how dependable the network is**.

A reliable network:

- Doesn't fail frequently
    
- Recovers quickly from failures
    
- Delivers data correctly
    

### ③ Security

Security protects the network and its data from unauthorized access and attacks.

It aims to provide:

- **Confidentiality** → Only authorized people can see the data.
    
- **Integrity** → Data is not improperly changed.
    
- **Availability** → Services remain accessible when needed.

# 6. Computer Network vs Data Communication

This is an important distinction.

|Data Communication|Computer Network|
|---|---|
|Focuses on transferring data|Focuses on interconnected devices|
|Sender and receiver exchange information|Multiple devices can communicate|
|Uses a transmission medium|Uses devices, links and protocols|
|Example: sending a message|Example: a college LAN|

**Easy way to remember:**

> **Data Communication = The process of exchanging data.**  
> **Computer Network = The system that enables devices to communicate and share resources.**
