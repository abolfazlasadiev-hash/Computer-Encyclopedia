## 03. Distributed Systems

A **Distributed System** is a system in which **multiple independent computers work together and appear to users as one unified system**.

### Simple definition

> **A distributed system is a collection of independent computers that communicate and coordinate with each other to perform tasks and provide services as a single system.**

---

### 1. Simple example

Think about **Google Search**.

When you search something, your request isn't necessarily handled by one computer. Many servers in different locations can work together:

```text
                  Your Computer
                       │
                       ↓
                 Internet
                       │
          ┌────────────┼────────────┐
          ↓            ↓            ↓
       Server 1     Server 2     Server 3
          │            │            │
          └────────────┼────────────┘
                       ↓
                  Combined Result
                       │
                       ↓
                  Your Computer
```

You see **one result**, even though many computers may have participated.

---

## 2. Main idea

The key idea is:

**Many computers + Communication + Coordination = One system**

The computers in a distributed system are called **nodes**.

Each node can have its own:

- Processor
    
- Memory
    
- Storage
    
- Operating system
    

But they communicate through a network and cooperate to accomplish a common goal.

---

## 3. Characteristics of Distributed Systems

### ① Multiple computers

A distributed system contains **more than one computer**.

### ② Communication

The computers communicate through a network.

### ③ Resource sharing

Computers can share:

- Files
    
- Data
    
- Processing power
    
- Storage
    
- Services
    

### ④ Concurrency

Several computers can perform tasks **at the same time**.

### ⑤ Scalability

More computers can often be added when more processing capacity is needed.

### ⑥ Fault tolerance

If one computer fails, the system may continue operating using other computers.

---

## 4. Examples

Common examples include:

- **Cloud computing systems**
    
- **Search engines**
    
- **Distributed databases**
    
- **Banking systems**
    
- **Online shopping systems**
    
- **Content delivery networks**
    
- **Large-scale web applications**

# 5. Distributed System vs Computer Network

This distinction is **very important**.

|Computer Network|Distributed System|
|---|---|
|Connects computers/devices|Uses multiple computers to work together|
|Main goal is communication/resource sharing|Main goal is providing a coordinated service|
|Users may see individual computers|Users may see the whole system as one system|
|Focus is on connectivity|Focus is on cooperation and coordination|

### Easy example

**Computer Network:**

```text
PC 1 ─── Switch ─── PC 2 ─── PC 3
```

The computers are connected and can communicate.

**Distributed System:**

```text
        User
          │
          ↓
    Distributed System
       ↙    ↓    ↘
    PC 1   PC 2   PC 3
```

PC 1, PC 2 and PC 3 **cooperate to provide a common service**.

---

## 6. Network vs Distributed System — easiest way to remember

> **Network:** "Computers are connected."

> **Distributed System:** "Computers are connected AND work together as one system."

---
