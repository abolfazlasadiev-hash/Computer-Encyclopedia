
**Network Architecture** describes the **overall structure and organization of a computer network**—how devices, communication links, protocols, and services are arranged and how they communicate.

Your syllabus lists **Network Architecture** under the basic concepts of computer networks.

### 1. Simple idea

Think of a network like a **company**:

```text
              NETWORK
                 │
       ┌─────────┴─────────┐
       │                   │
    Devices             Rules
       │                   │
 Computers              Protocols
 Servers                TCP/IP
 Routers                HTTP
```

The architecture tells us **how these parts are organized and how they interact**.

---

## 2. Two important architectures

### A. Client–Server Architecture

A **client** requests a service, and a **server** provides it.

```text
 Client 1 ──┐
 Client 2 ──┼──→ SERVER
 Client 3 ──┘       │
                    ↓
                Service/Data
```

**Example:**  
When you open a website, your browser acts as a **client** and requests information from a web server.

**Advantages:**

- Centralized management
    
- Easier security and administration
    
- Data can be stored centrally
    

**Disadvantage:**

- If the central server fails, its services may become unavailable.
    

---

### B. Peer-to-Peer (P2P) Architecture

In **peer-to-peer architecture**, computers can communicate directly and may act as **both clients and servers**.

```text
        PC 1
       ↙    ↘
     PC 2 ─── PC 3
       ↘    ↙
        PC 4
```

There isn't necessarily one central server controlling everything.

**Example:**  
Some file-sharing systems use peer-to-peer communication.

**Advantages:**

- No single central server is required
    
- Resources can be shared directly
    

**Disadvantages:**

- More difficult to manage
    
- Security can be more complicated
    

---

## 3. Why network architecture matters

A good architecture helps determine:

- How devices communicate
    
- Where services are provided
    
- How resources are shared
    
- How the network is managed
    
- How easily the network can grow
    
- How security is implemented
    

---

### ⭐ Exam definition

> **Network architecture is the design and organization of a computer network, including its devices, communication methods, protocols, and the way different components interact with each other.**

### Remember

**Client–Server:**

> Client **requests** → Server **provides**

**Peer-to-Peer:**

> Peers **communicate and share directly**
