
**Network applications** are the programs and services that use a computer network to allow users or devices to communicate, exchange data, access resources, and perform useful tasks.

In simple terms:

> **A network provides the connection; network applications use that connection to do something useful.**

For example, when you open a website, send an email, download a file, or join a video call, you are using a **network application**.

### Common Network Applications

|Application|Purpose|Example|
|---|---|---|
|**Web browsing**|Access websites and web services|Chrome, Firefox|
|**Email**|Send and receive messages|Gmail, Outlook|
|**File transfer**|Upload/download files|FTP, SFTP|

### How a Network Application Works

Consider opening a website:

**User → Web Browser → Network → Web Server → Network → Browser → User**

For example:

1. You enter `example.com`.
    
2. **DNS** finds the server's IP address.
    
3. Your computer establishes communication with the server.
    
4. The browser sends an **HTTP/HTTPS request**.
    
5. The web server processes the request.
    
6. The server sends a response.
    
7. Your browser displays the webpage.
    

So several network protocols can work together to provide one application.

### Important Network Applications in Computer Networks

#### 1. Web Application

Used to access information and services through the Internet.

Main protocols:

- **HTTP**
    
- **HTTPS**
    

Example: visiting an online shopping website.

#### 2. Email

Allows users to send and receive electronic messages.

Common protocols:

- **SMTP** → sending email
    
- **POP3** → downloading email
    
- **IMAP** → accessing/synchronizing email
    

#### 3. File Transfer

Used to move files between computers.

Protocols include:

- **FTP**
    
- **SFTP**
    
- **TFTP**
    

#### 4. Remote Login

Allows a user to access another computer over a network.

- **SSH** — secure remote access
    
- **Telnet** — older, insecure remote-access protocol
    

#### 5. DNS

The **Domain Name System** translates human-readable names into IP addresses.

For example:

`www.example.com`  
↓ DNS  
`IP address`

Without DNS, users would generally have to remember numerical IP addresses.

#### 6. Multimedia and Streaming

Networks allow continuous delivery of audio and video.

Examples:

- Video streaming
    
- Music streaming
    
- Live broadcasting
    
- Video conferencing
    

These applications are particularly sensitive to **delay, jitter, bandwidth, and packet loss**.

#### 7. Cloud Applications

Applications and resources can be accessed through networks instead of being entirely stored or executed locally.

Examples:

- Cloud storage
    
- Online document editors
    
- Cloud databases
    
- SaaS applications
    

---

### Key Idea for Exams

Don't confuse **network application** with **network protocol**.

- **Application** = what the user wants to accomplish.
    
- **Protocol** = rules used for communication.
    

For example:

> **Email** is an application, while **SMTP** is a protocol used to send email.

Similarly:

> **Web browsing** is an application, while **HTTP/HTTPS** are protocols used by web applications.

### One-line Definition

**Network applications are software applications that communicate and exchange information over a computer network to provide services to users.**
