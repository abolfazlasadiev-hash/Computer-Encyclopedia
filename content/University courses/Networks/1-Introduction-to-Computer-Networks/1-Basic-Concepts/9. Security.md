
In **computer networks**, **security** means protecting **data, devices, users, and network resources** from unauthorized access, misuse, modification, destruction, or disruption.

### Simple Definition

> **Network security is the practice of protecting a network and its data from unauthorized access, attacks, and damage.**

---

## Main Goals of Network Security

The three most important goals are called the **CIA Triad**:

### 1. Confidentiality

**Confidentiality** means that data should be accessible **only to authorized users**.

Example:

You send a private message. An unauthorized person should not be able to read it.

Methods used:

- Encryption
    
- Access control
    
- Authentication
    

---

### 2. Integrity

**Integrity** means that data should remain **accurate and unchanged** unless an authorized person modifies it.

Example:

You send:

> Transfer $100

An attacker should not be able to change it to:

> Transfer $10,000

Methods used:

- Hashing
    
- Digital signatures
    
- Integrity checks
    

---

### 3. Availability

**Availability** means that network resources and services should be **available to authorized users when needed**.

Example:

A company's website should remain accessible to customers.

Threats to availability include:

- DoS attacks
    
- DDoS attacks
    
- Hardware failures
    
- Network congestion
    

---

# Other Security Goals

### 4. Authentication

**Authentication** verifies **who a user or device is**.

Examples:

- Username and password
    
- OTP
    
- Biometrics
    
- Digital certificates
    

Example:

```text
User → "I am Alice"
       ↓
System verifies identity
       ↓
Access granted
```

---

### 5. Authorization

**Authorization** determines **what an authenticated user is allowed to do**.

For example:

- Student → Can view grades
    
- Teacher → Can enter grades
    
- Administrator → Can modify system settings
    

So:

> **Authentication = Who are you?**  
> **Authorization = What are you allowed to do?**

---

### 6. Non-Repudiation

**Non-repudiation** provides evidence that a particular person or system performed an action, making it difficult for them to later deny it.

A common technology used is a **digital signature**.

Example:

Alice digitally signs a document.

Later, Alice cannot easily claim:

> "I never signed that document."

---

# Common Network Security Threats

Networks can face many types of attacks.

### 1. Malware

Malicious software designed to damage systems or steal information.

Examples:

- Virus
    
- Worm
    
- Trojan
    
- Ransomware
    

### 2. DoS

**Denial of Service (DoS)** attempts to make a service unavailable by overwhelming or disrupting it.

### 3. DDoS

**Distributed Denial of Service (DDoS)** uses many systems to attack a target simultaneously.

### 4. Spoofing

An attacker **pretends to be another device or user**.

Examples:

- IP spoofing
    
- MAC spoofing
    
- Email spoofing
    

### 5. Sniffing

An attacker captures network traffic to observe information being transmitted.

Encryption helps protect sensitive data from being understood even if traffic is captured.

### 6. Man-in-the-Middle (MITM)

An attacker secretly positions themselves between two communicating parties.

```text
Alice ───→ Attacker ───→ Bob
          ↑
       intercepts
       communication
```

### 7. Phishing

An attacker attempts to trick users into revealing information such as passwords or financial details, often through fake emails or websites.

# Common Security Techniques

## Firewall

A **firewall** controls network traffic according to security rules.

```text
Internet
   │
   ▼
[ Firewall ]
   │
   ▼
Internal Network
```

It can allow legitimate traffic and block unwanted traffic.

---

## Encryption

**Encryption** converts readable data (**plaintext**) into an unreadable form (**ciphertext**).

```text
Plaintext
   ↓ Encryption
Ciphertext
   ↓ Decryption
Plaintext
```

It helps provide **confidentiality**.

---

## Antivirus / Endpoint Protection

Software designed to detect and block malicious software.

---

## VPN

A **Virtual Private Network (VPN)** creates a protected communication tunnel over a network.

It is commonly used to protect traffic when communicating over untrusted networks.

---

## Authentication

Ensures that only legitimate users can access resources.

---

# Security vs Reliability vs Performance

These are three important network criteria:

|Criterion|Main Question|
|---|---|
|**Performance**|How fast and efficiently does the network work?|
|**Reliability**|How consistently does the network work?|
|**Security**|How well is the network protected?|

### Easy Example

Imagine a bank network:

- **Performance** → Transactions should be processed quickly.
    
- **Reliability** → The banking service should remain operational.
    
- **Security** → Unauthorized people must not access or modify accounts.
    

---

## ⭐ Exam Point

Remember the **CIA Triad**:

**C — Confidentiality** → Prevent unauthorized reading  
**I — Integrity** → Prevent unauthorized modification  
**A — Availability** → Keep services accessible

### Exam Definition

> **Network security is the protection of network resources, devices, communications, and data against unauthorized access, modification, disclosure, attacks, and disruption.**
